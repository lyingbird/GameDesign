# 《噬变防线 (Mutaline)》GDD 策划案 v0.2

> 一句话立项：**单人塔防 roguelite —— 你的塔在击杀怪物后吸收其「变异基因」进化分支，每一局都长出一套不同的塔体系。**

---

## 1. 游戏概述
一款面向单人/小团队的**塔防 × 肉鸽构筑**游戏。玩家在程序化生成的关卡中布防、抵御波次；核心钩子是**塔的进化来自击杀本身**——怪物死亡掉落「变异基因」，塔吸收后在三条进化路线中分支成长。每局通过「击杀→进化→再击杀」的正反馈滚雪球，组合出独一无二的塔阵；失守则带永久解锁重开。

- **平台**：PC（Steam），手柄/鼠键。
- **目标受众**：塔防策略玩家 + 肉鸽构筑爱好者（Vampire Survivors / Isle of Arrows 受众交集）。
- **单局时长**：15–25 分钟（控制肉鸽的轻快感）。

## 2. 核心幻想
> **「我亲手喂养的塔，越杀越强，最后长成一台我从没预料到的杀戮机器。」**

玩家扮演一名「变异工程师」，不是堆砌固定炮塔，而是**引导进化**：决定哪座塔吃哪种基因、走哪条分支。情感目标是**养成 + 发现**——既有塔防的掌控感，又有肉鸽「这一局会长成什么样」的惊喜。

## 3. 设计支柱与反支柱
**Must-Have 支柱**
1. **击杀即进化** — 进化资源（基因）只能靠战斗获取，把「打」和「养」焊死成一个循环；任何系统都要服务这条反馈链。
2. **每局长出不同塔体系** — 随机基因池 + 分支选择，保证重玩性来自组合爆炸而非手工内容。
3. **少而精的协同** — 塔与基因两两能「生火」，深度来自组合而非数值堆砌。

**反支柱（首版明确不做）**
- 联机/PvP（单人专注，避开平衡与服务器负担）。
- 巨量手工关卡（用程序化 + 构筑替代内容量）。

## 4. 品类定位与竞品
**一句话定位**：把 *Vampire Survivors* 的「击杀→三选一进化」滚雪球，装进 *Isle of Arrows* 式的塔防布局里。

| 对标作 | 借鉴 | 差异锚点 |
|---|---|---|
| Isle of Arrows | 塔防 + roguelite 抽取、小团队可行性 | 我们的进化由**击杀驱动**，非回合抽地块 |
| Vampire Survivors | 进化滚雪球的多巴胺节奏 | 我们保留**塔防布局**的空间策略层 |
| Bloons TD 6 | 塔的多路升级深度 | 升级路线由**战斗中掉落的基因**解锁，而非纯花钱 |

**差异化核心**：进化资源 = 击杀产物，使「选哪座塔站哪个杀点」成为构筑决策本身。

## 5. 核心循环
- **微循环（10–30s）**：怪物进入路径 → 塔攻击击杀 → 掉落变异基因 → 拾取累积。
- **中循环（一关 / 一波组）**：波次结束 → 用本关基因为某座塔**三选一进化分支** → 调整布局迎接下一波。
- **宏循环（一局 run，15–25min）**：连过 N 关，构筑成型滚雪球 → 通关或失守 → 结算永久解锁（新基因/新塔/新地图）→ 开下一局。

**核心正反馈链**：击杀 → 基因 → 进化 → 更强击杀 → 更多基因。张力来自「进化速度 vs 波次 HP 指数增长」的**竞速**。

## 6. 系统设计
| 优先级 | 系统 | 说明 |
|---|---|---|
| **P0（MVP 闭环）** | 塔防战斗核心 | 6–8 种基础塔 + 抗性矩阵（物理/元素/穿透）；格位放置 + 路径波次 |
| **P0** | 进化系统 | 基因掉落 → 三选一分支（每塔 3 条进化树，每树 2–3 层） |
| **P0** | 局内构筑资源 | 基因（跨关累积，绑定到具体塔） |
| **P1** | 协同系统 | 基因词条间的组合爆发（毒+扩散、冰+碎冰…） |
| **P1** | 元进度 | 永久解锁基因池/起始塔/地图 |
| **P2** | 程序化关卡/波次 | 随机地图布局与波次成分 |
| **P2** | 风险-回报抉择 | 精英波换稀有基因、诅咒换强化 |

**最小可玩闭环 = 战斗核心 + 进化 + 基因**（P0 三项即可验证「击杀即进化」是否好玩）。

## 7. 资源经济
**双重经济**（继承 TD-roguelite 范式）：
| 资源 | 源（产出） | 汇（消耗） | 闭环说明 |
|---|---|---|---|
| 金钱（局内即时） | 击杀小额掉落 | 建塔 / 即时升级 | 关卡内花光，不跨关 |
| 变异基因（构筑资源） | 击杀掉落（精英多掉） | 三选一进化分支 | 跨关累积成 build，绑定具体塔 |

- **闭环风险**：基因产出 = 击杀数，若前期击杀不足则进化停滞 → 设「保底基因」（每关至少给 1）防摆烂。
- **通胀护栏**：后期击杀暴增→基因溢出→进化封顶（每塔进化层数有上限），溢出基因转少量金钱。

## 8. 数值框架
- **波次难度**：第 k 关总 HP ≈ `base × 1.18^k`（指数 scaling，与构筑成型竞速）。
- **塔伤害**：`DPS = 基础攻 × (1 + Σ加法词条) × Π独立乘区`。**关键护栏**：每类乘区（暴击/增伤/元素）独立封顶，防几个乘区相乘一关清屏。
- **进化收益**：每次分支约 +30–50% 战力，3 层进化后单塔约为初始 4–6×（量级，非死数）。
- **基因掉落**：普通怪 8% / 精英 100% / Boss 保底 3 个。
- **经济基准**：建塔成本 100→曲线，关卡金钱产出约够「2 塔 + 3 升级」，逼出取舍。

> 以上为方向与量级，需用模拟脚本（可接 `numeric-audit` skill）验证 build 滚雪球曲线，防乘区失控。

## 9. 内容规划
- **首版内容量（MVP）**：6 塔 × 3 进化树 = 约 18 个进化终点；12–15 种基因词条（侧重两两协同）；3 张程序化地图；15 关一局。
- **可复用性**：内容量靠「塔 × 基因」组合空间放大，而非手工关卡。
- **里程碑**：① 灰盒验证「击杀即进化」手感（仅 P0）→ ② 加协同 + 元进度 → ③ 程序化关卡 + 平衡打磨。

## 10. 风险与待定
| 等级 | 风险 / 待验证假设 | 缓解 |
|---|---|---|
| 高 | **统治组合**：某基因协同碾压，策略坍缩 | 强协同设为稀有、可遇不可求；模拟验证 |
| 高 | **随机不公平**：开局没核心基因就摆烂 | 保底基因 + 可重抽一次 |
| 中 | 乘区失控，中段 break 游戏 | 独立乘区 + 封顶（见 §8） |
| 中 | 布局层与构筑层割裂（基因不影响站位策略） | 设计「位置相关」基因（如「击杀拐角怪 +伤」） |
| 低 | 单局过长削弱轻快感 | 关数/波速调优，目标 ≤25min |

**首版不做**：联机、巨量手工关卡、复杂剧情。
