# 动作角色扮演 / 刷宝 (ARPG / Hack-and-Slash)

## 核心循环
战斗清怪 → 掉落装备/材料 → 装备升级带来战力提升 → 打更高难度的怪/区域 → 掉更好的装备 → 围绕装备词缀构筑 build（技能 + 装备协同）→ 反复"刷"以追求极品装备。核心快感是**"杀怪掉宝→变强→杀更强的怪"的装备驱动正反馈（loot loop）+ 构筑深度**。

## 关键子系统
- **战斗系统**：技能释放、连招、走位躲避，海量怪同屏的爽快割草感（屏幕清场反馈）。
- **装备/掉落系统 (loot)**：装备稀有度分级（白/蓝/黄/暗金/传奇）、**随机词缀（affix）**组合是品类核心——同一件装备因词缀不同价值天差地别。
- **角色构筑 (build)**：技能树/技能符文 + 装备词缀的组合，决定玩法流派（火法/召唤流/暴击流）。深度 build 系统是长线动力。
- **难度分层**：普通→困难→地狱/痛苦层级，更高难度=更好掉落，构成"刷"的阶梯。
- **数值养成**：等级、属性点、抗性、装备评分。
- **终局内容 (endgame)**：满级后的核心循环（如地图系统、深渊、词条挑战），决定长留存。

## 经济/数值要点
- **装备词缀的随机性 = 掉落多巴胺引擎**。期望值需精算：词缀池大小、稀有词缀概率、极品（完美词缀）概率，控制"刷到神装"的稀有度以维持长期目标。
- 战力是**乘法堆叠**（伤害 = 基础 × 技能加成 × 暴击 × 词缀 × ...），易指数失控，需设计独立乘区与软上限。
- 怪物 HP/伤害随难度层级指数 scaling，与玩家装备战力曲线竞速；终局需"无限层"承载战力膨胀。
- 经济：货币/材料用于装备改造（强化/重铸/镶嵌），制造资源沉没与追求。
- **power creep** 风险高：版本更新加装备易让旧内容贬值。

## 经典参考作品
- **Diablo II / III / IV**：品类奠基，掉落分级 + 技能加点/符文 + 难度层级，定义"刷宝"循环。
- **Path of Exile**：构筑深度天花板——巨型被动天赋树 + 技能宝石链 + 装备词缀 + 地图系统，免费但极硬核。
- **Grim Dawn**：双职业混搭 build，叙事 + 刷宝平衡良好的单机标杆。
- **Last Epoch**：技能专精树 + 物品工艺系统，降低 PoE 复杂度的现代化设计。
- **Torchlight / Victor Vran**：更轻量化、卡通化的 ARPG 变体，适合理解品类下限。
- **Diablo-like 手游（如暗黑破坏神：不朽）**：理解 ARPG 与抽卡/付费养成的结合（及争议）。

## 常见坑
- **装备掉落体验差**：99% 是垃圾（自动分解还是手动捡？背包管理负担），多巴胺被噪声淹没。需聪明的掉落过滤与稀有度反馈。
- 数值乘区失控，几件装备 break 游戏，或反之"毕业"后无追求。
- 终局内容单薄，满级即弃游（endgame 是 ARPG 长留存的真正战场）。
- build 多样性不足，存在唯一最优流派。
- 刷的过程过于重复枯燥（无新机制注入）。

## 单人/小团队可行性
中等偏难。**内容量（技能、装备词缀池、怪物、关卡、终局系统）是主要成本**，且数值/掉落平衡工作量大。但纯单机 ARPG 不需要联机，技术门槛低于 PvP 品类。小团队策略：① 聚焦**构筑深度而非内容广度**——少而精的技能 + 丰富词缀组合，重玩性来自 build 而非美术量；② 借鉴 Roguelite 结构（局内随机构筑）压缩终局内容需求；③ 程序化生成关卡/掉落降低手工内容成本。先把"杀怪掉宝变强"的核心 loot loop 调出瘾，再扩 build 与 endgame。
