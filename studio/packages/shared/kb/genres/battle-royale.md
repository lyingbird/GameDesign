# 大逃杀 (Battle Royale)

## 核心循环
跳伞/空降到大地图 → 搜刮装备（looting）→ 在不断缩小的安全区内移动 → 遭遇战斗/规避 → 升级装备、占据优势位置 → 决赛圈对决 → 最后存活者/队伍获胜（"吃鸡"）。核心张力是**搜刮发育 vs 战斗风险 + 毒圈逼迫的时间压力**。单局一次性，死亡即出局重开。

## 关键子系统
- **缩圈系统 (the circle/zone)**：安全区周期性收缩 + 区外伤害，是 BR 的发明与灵魂——强制玩家相遇、压缩节奏、制造决赛圈。圈的随机位置与收缩节奏是核心调参。
- **搜刮/装备系统 (loot)**：武器/护甲/配件/消耗品的稀有度分级与随机分布，开局"裸奔→武装"的发育曲线。
- **大地图设计**：地名/资源点（hot drop 高资源高风险 vs 偏远安全发育）、地形多样性、载具。
- **战斗系统**：通常基于 FPS/TPS 射击，倒地（knock）+ 队友救援机制（小队 BR）。
- **存活/淘汰**：百人同场，无重生（或限定复活机制），单局 20-30 分钟。

## 经济/数值要点
- **缩圈节奏曲线**是体验核心：早圈大而慢（给搜刮发育时间），后圈小而快（逼迫高密度对决）。区外伤害随阶段递增。
- 装备稀有度概率分布决定"运气 vs 实力"的比重——发育不平等是 BR 张力来源也是挫败来源，需把握度。
- 人数衰减曲线：开局百人混战快速淘汰一批，中期稀疏，决赛圈紧张。
- 通常**对局结果不直接给数值成长**（盈利靠外观/battle pass），避免 pay-to-win 破坏公平竞技。

## 经典参考作品
- **PUBG（绝地求生）**：定义现代 BR——百人、缩圈、搜刮、拟真射击，奠定模板。
- **Fortnite**：加入建造系统（搭墙/造塔）作为核心差异化，免费 + 联动 + 演出运营的现象级商业模式。
- **Apex Legends**：小队 BR + 英雄技能 + ping 标记 + 倒地救援/重生信标，团队协作设计标杆。
- **Warzone（使命召唤）**：大体量 BR + 古拉格（淘汰后 1v1 争复活），降低一死即出局的挫败。
- **Fall Guys**：把 BR 框架（百人→淘汰→最后赢家）套到派对闯关上，证明"大逃杀结构"可跨题材。

## 常见坑
- **"死太快、等太久"**：落地即被淘汰却要看完整局，挫败感强。需复活/观战队友/快速重开机制缓解。
- 搜刮运气过重，实力强但开局空军直接出局，公平感差。
- 缩圈节奏失调（太慢拖沓、太快混乱）。
- 大地图制作成本高，且需持续更新防止审美疲劳。
- **致命要害：没有海量玩家就无法填满一局**——匹配失败则游戏不存在（强网络效应壁垒）。

## 单人/小团队可行性
**极低，几乎不适合 solo/小团队做成正统 BR**。三大无底洞：① 百人级实时网络同步与服务器成本；② 巨型地图美术工作量；③ 必须有海量并发玩家才能成局（冷启动死亡螺旋）。小团队若想触碰，唯一务实路径是**借用"缩圈淘汰"结构做小规模/异步/PvE 变体**（如低人数、机器人填充、或 Fall Guys 式派对化），把"百人实时 PvP"这个核心成本项拿掉。直接照搬 PUBG/Apex 的全规格方案对小团队是项目自杀。
