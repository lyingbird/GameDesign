# 第一人称射击 (FPS)

## 核心循环
观察战场 → 移动走位/占点 → 瞄准射击/换弹/投掷 → 击杀/被击杀 → 获取击杀奖励或重生 → 推进目标（占点/护送/歼灭）。核心是**毫秒级的瞄准-移动-决策手感**。微循环=一次交火（开镜-射击-掩护）；中循环=一个回合/一波目标；宏循环=一局比赛/一段战役。

## 关键子系统
- **射击手感 (gunplay)**：后坐力曲线、散布、TTK（time-to-kill）、命中反馈（命中音/血液/标记）、武器手感差异化。是 FPS 的灵魂，决定一切。
- **移动系统**：速度、跳跃、滑铲、冲刺、惯性——决定走位与对枪节奏（对比 CS 的站定射击 vs Apex 的高机动）。
- **武器系统**：弹道、伤害衰减、配件改装、武器分类与定位。
- **地图设计**：交火点（power position）、路线、视野遮挡、点位平衡——竞技 FPS 的核心工艺。
- **模式**：PvP（占点/爆破/团死）/ PvE（战役/合作）/ 大逃杀 / 撤离。
- **进度系统**：解锁武器/皮肤、battle pass（多为外观，避免 pay-to-win）。

## 经济/数值要点
- **TTK 是核心调参**：低 TTK（CS：一两枪）→ 强调先手与意识，高 TTK（守望/Apex）→ 强调持续追踪与团队火力。决定整个游戏的体验基调。
- 伤害随距离衰减、爆头倍率、护甲减免——构成命中数学；需让每把枪有清晰的"最优交战距离"。
- 经济模式（如 CS 的买枪经济）：击杀/回合奖励 → 影响买枪决策，制造回合策略层。
- 网络层的**命中判定**（客户端预测、滞后补偿、tick rate）直接影响公平感，是技术核心。

## 经典参考作品
- **Counter-Strike（CS:GO/CS2）**：站定精准射击 + 买枪经济 + 爆破模式，竞技 FPS 的纯净标杆，地图平衡工艺。
- **DOOM (2016/Eternal)**：单人 PvE，"血腥处决回血"逼迫进攻性玩法，移动与资源循环设计典范。
- **Apex Legends**：大逃杀 + 英雄技能 + 高机动移动 + 标记（ping）系统，融合创新。
- **Overwatch**：英雄 FPS，技能/角色定位把 FPS 与 MOBA 缝合。
- **Valorant**：CS 精准射击 + 英雄技能，反作弊与战术技能融合。
- **Half-Life / Portal**：单人叙事/解谜 FPS，证明第一人称不止于对枪。

## 常见坑
- 射击手感不过关——这是 FPS 的命门，手感差则一切免谈，需大量迭代打磨。
- 武器平衡失衡，出现"必选武器"，多样性坍缩。
- 地图点位失衡（一方天然优势、狙击点过强、绕后路线缺失）。
- 联机 FPS 的作弊（外挂）与网络延迟会摧毁体验，反作弊是持续战争。
- 大逃杀/竞技模式没有玩家基数则匹配失败。

## 单人/小团队可行性
**两极分化**。竞技/多人 FPS 对 solo/小团队**极不友好**（手感打磨、网络同步、反作弊、平衡、玩家基数全是重负担）。但**单人 PvE FPS 完全可行**——boomer shooter 复兴（如 Dusk、Ultrakill 由小团队/个人完成）证明：聚焦扎实的 gunplay + 敌人设计 + 关卡，无需联机即可成立。小团队建议走 PvE/叙事/Roguelite-FPS 方向，把全部精力投在手感与关卡上，规避网络与平衡的无底洞。
