# 抽卡养成 (Gacha)

## 核心循环

消耗抽卡货币（石头/票/体力兑换）→ 拉取卡池获得角色或装备 → 对获得内容进行养成（突破/技能升级/专武/好感）→ 用培养成果攻克关卡/副本/活动 → 关卡奖励回补货币 → 等待（限时活动/新角色 UP 池）→ 再次抽取。快感分为两层：**稀缺性惊喜**（SSR 命中瞬间的强刺激）与**长线成长感**（角色从 0 培养到满命/满潜的慢烧满足）。限定角色与限时活动将两层快感叠加，推动氪金高峰。

## 关键子系统

- **卡池与概率机制**：基础出率（通常 SSR 0.6%–3%）+ 软保底（概率随抽数递增）+ 硬保底（pity，抽满 N 抽必得 SSR）；UP 池在保底内额外保证指定角色概率（50/50 或 75/25 机制）；精确的 pity 计数跨池是否继承是影响玩家留存的关键设计点。
- **货币分层**：免费货币（体力/任务/活动）与付费货币分开，或通用但付费加速；月卡/通行证提供低门槛持续收益，拉开 F2P 与微氪之间的分水岭。
- **角色/装备养成**：多轴深度养成（等级/突破/技能/专武/圣遗物/好感/命座/星级），每轴都需要专属材料；深度养成让每个新 SSR 成为长周期投入目标，延长留存。
- **活动与 Battle Pass**：限时活动是流水高峰；永久活动通行证（Battle Pass）月卡化提供稳定收入下限；活动剧情绑定限定角色，强化 FOMO（错过恐惧）。
- **社交/战力展示**：排行榜、深渊/末日计分、角色展示间——竞争压力推动养成深度和氪金动机；纯 PvP 因养成差距引发平衡争议，多数产品选择 PvE 竞速/评分代替直接对战。
- **内容版本节奏（运营日历）**：每版本（通常 3–6 周）新增角色+剧情+活动+地图，节奏决定玩家活跃周期；日历断档或版本质量下滑会导致批量流失。

## 经济/数值要点

- **付费率与 ARPU**：付费率通常 2%–10%，但头部付费用户（鲸鱼/大 R）贡献 60%–80% 流水；设计时要保证 F2P 也有完整游戏体验，以维持用户基数供鲸鱼"展示"。
- **抽卡期望成本**：一个 UP 角色的期望抽数约为 soft pity 触发点的 1.5–2 倍（各家实现不同）；全命座/满命通常需要 7 倍基础抽数，是区分轻氪与重氪的设计门控。
- **材料经济**：每种养成轴对应独立材料体系，体力是每日获取上限；材料瓶颈（树脂/体力回复付费加速）是主要变现点之一。
- **活动货币与资源发放**：每期活动赠送的免费货币数量影响 F2P 抽数预算，设计时需在"慷慨留人"与"逼迫付费"之间校准。
- **版本流水预测**：新 SSR 角色流水与其"强度 + 限定性 + 剧情曝光量"正相关；数值策划需对每角色的战力曲线做横向校准，避免快速通货膨胀侵蚀旧角色价值。

## 经典参考作品

- **原神（Genshin Impact）**：将 Gacha 与开放世界探索结合的标杆；元素反应系统提供深度；F2P 友好的抽取频率与高质量剧情提升了品类口碑上限。
- **阴阳师（Onmyoji）**：早期确立国产 gacha 二次元美术 + 和风 IP 路线；式神召唤体系与碎片合成双轨并行，降低纯随机挫败感。
- **Fate/Grand Order（FGO）**：剧本驱动留存的极端案例；低出率高 pity 成本但强剧情 IP 造就高付费黏性，证明"内容力"可以弥补"体验友好度"不足。
- **明日方舟（Arknights）**：将塔防策略与 gacha 结合，强调技能与站位而非纯数值；干员平衡性较好，低星干员有实用价值，削弱了强氪动机但换取了高口碑。
- **崩坏：星穹铁道（Honkai: Star Rail）**：回合制 RPG + gacha 的现代示范；双轨 pity（角色+光锥）及 50/50 保底继承机制成为玩家友好度的行业参照点。

## 常见坑

- **pity 设计不透明**：概率表含糊、软保底触发点不公示，玩家不信任机制导致口碑崩塌——监管政策（国内要求公示概率）也倒逼透明化。
- **养成轴过多导致新手劝退**：同时开放 8 个养成维度、材料体系割裂、早期引导不足，新玩家在感受到快感前已放弃。
- **限定滥发或过度饥饿营销**：限定角色过多使"限定"稀缺感稀释；或限定池间隔太短导致玩家存不到保底，两者都损害长期信任。
- **版本内容断档**：运营日历出现空窗期，玩家在无事可做时流失，且 gacha 游戏的再次激活成本极高（玩家归来后面对大量积压养成内容易产生压迫感）。
- **PvP 数值失衡**：以养成深度决定 PvP 胜负会使 F2P 感到强制付费，损害社区氛围；多数成功产品将 PvP 设计为技巧竞速或限定配置，而非开放数值对抗。
- **强度通货膨胀**：新版本角色持续强于旧版本（power creep），快速侵蚀旧 SSR 价值，迫使玩家不断追新抽取，短期流水上升但长期信任下降。

## 单人/小团队可行性

**难度极高，几乎不适合纯单人或小团队**。原因：① 运营型产品，上线才是开始，需要持续的版本内容产出（剧情+角色+活动），对写手、美术、策划的持续投入要求极高；② 高质量角色美术（立绘+动态+Live2D/3D）是获客核心，单人产能严重不足；③ 后端服务（账号系统、卡池服务器、防抓包、支付通道）需要专业工程能力；④ 合规红线（概率公示、未成年限制、支付审核）需法务与商务资源。**可行路径**：做"弱 gacha"变体——以固定价格解锁角色（如买断制角色卡）、轻量合集玩法（不含养成深度）、或 Demo 级概念验证；若坚持做完整 gacha 产品，至少需要 5–10 人跨职能团队 + 充足启动资金 + 完整运营计划，且需做好 1–2 年才能验证市场的心理准备。
