# 挂机/增量 (Idle / Incremental)

## 核心循环
积累资源（自动产出 + 主动点击）→ 购买产出单位/升级 → 产出加速 → 解锁新层级 → 触顶后**转生/重置（prestige）换取永久加成**→ 以更快速度重跑。核心快感是**"数字爆炸式增长"与"花钱买更快增长"**。微循环=买下一个升级；宏循环=每次 prestige 跨越一个数量级。

## 关键子系统
- **产出链 (generator chain)**：多级生产者，低级产高级所需资源，常见"买 A 产 B、买 B 产 A 的资源"形成自动化链条。
- **升级/加成系统**：乘区设计（加法区、乘法区、指数区分离），里程碑解锁（如"拥有 25 个 X 时 X 产出 x2"）。
- **转生/声望层 (prestige layers)**：软重置换永久货币；高级游戏有多层嵌套重置（如 Antimatter Dimensions 的多次重置维度）。
- **离线收益**：关闭游戏后按时长结算（常打折），是"挂机"体验的核心。
- **解锁节奏 / 内容墙**：用"暂时算不动的大数"作为下一阶段的诱饵。
- **自动化**：后期把手动操作自动化（auto-buyer），让玩家从操作转向策略。

## 经济/数值要点
- **数字范围极大**，需 BigNumber/对数表示（double 不够），UI 用科学计数法 / 后缀（K/M/B/T/aa/ab…）。
- 成本通常**指数增长**（cost = base · r^n，r≈1.07~1.15），产出线性或多项式增长，制造"买不动"的天花板，逼 prestige。
- prestige 货币产出常用 sqrt 或 log 关系挂钩本轮成就，保证每次重置有提升但收益递减。
- **关键是"等待时间"的曲线**：每个台阶等待应在"够痛促使升级、又不至弃游"之间。新台阶解锁后应有一段爽快加速期。
- 警惕**通胀失控**：某加成乘区无上限会让数值在几步内突破宇宙，破坏节奏。

## 经典参考作品
- **Cookie Clicker**：定义品类。建筑产出链 + 升级 + 天堂转生 + 黄金饼干随机事件；幽默文案撑起长线。
- **Adventure Capitalist**：清晰的"经理自动化 + 投资人 prestige"双层，离线收益体验标杆。
- **Antimatter Dimensions**：把增量做成深度数学谜题，多层嵌套重置（维度→无穷→黑洞），证明增量可以很硬核。
- **Melvor Idle**：把 RuneScape 的技能系统做成全挂机 RPG，多技能并行 + 离线战斗，长线内容典范。
- **Universal Paperclips**：叙事驱动的增量，机制随阶段彻底变形（制造→投资→宇宙），证明增量可承载强叙事。

## 常见坑
- **中期真空墙**：某段等待过长且无新机制注入，玩家流失。每个数量级都应有"新东西"。
- prestige 来得太晚或收益不明显，玩家感受不到"重开变强"的爽点。
- 全自动后无决策，沦为纯看数字。需保留有意义的乘区分配/路线取舍。
- 数值溢出 bug（用错数字类型）；离线收益结算错误。
- 平衡测试难：人手玩到后期不现实，需写模拟器跑曲线。

## 单人/小团队可行性
极高，几乎是 solo 开发的标志品类（很多爆款是一人作品）。逻辑以数值/状态为主，美术可极简（文字 + 图标）。**核心难点不是技术而是数值曲线调优**——强烈建议写一个离线模拟脚本，自动跑通"无人值守需要多久到达每个里程碑"，可视化等待曲线，避免靠手感拍脑袋。建议先做单层产出链 + 一次 prestige 跑通爽点，再加层。文案/主题（如《典藏图书馆》魔法图书馆挂机）是低成本差异化关键。
