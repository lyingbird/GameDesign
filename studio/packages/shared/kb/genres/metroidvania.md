# 银河城 (Metroidvania)

## 核心循环
探索互联的大地图 → 遇到无法通过的障碍（门控 gate）→ 寻找并获得新能力（二段跳/冲刺/破墙）→ 用新能力回到之前去不了的区域（backtracking）→ 解锁新地图与道具 → 战斗成长 + 发现秘密 → 推进至 boss/剧情。核心快感是**"获得能力→世界豁然开朗→发现新路"的探索-赋能循环**。

## 关键子系统
- **能力门控 (ability gating)**：用能力锁住区域（没有二段跳上不去、没有水下呼吸进不去），获得能力即解锁新空间。这是品类的结构骨架。
- **互联地图设计**：一张精心编织、回路丰富的地图，捷径解锁制造连通感。地图设计是品类的核心工艺与最高难度。
- **能力/移动系统**：每个能力既是钥匙（解门）又是工具（战斗/移动），需双重价值。
- **战斗系统**：通常 2D 动作，敌人 + boss（常作为能力守门人）。
- **探索奖励**：隐藏道具、血量/能量上限提升、可选区域——奖励好奇心。
- **地图/导航 UI**：可标记的地图是体验关键（让 backtracking 不痛苦）。

## 经济/数值要点
- 多为**轻数值**品类——成长靠"能力解锁"（质变）而非数值堆叠（量变）。血量/能力上限提升是主要数值成长。
- 关键设计变量是**能力的获取顺序与门控编排**：哪个能力解锁哪片区域、回溯路径多长，决定整个游戏的节奏与"开图"爽感分布。
- 战斗数值（敌人 HP/伤害）相对简单，服务于探索而非作为核心追求。
- 经济（货币/商店）通常是次要系统，用于补给或可选升级。

## 经典参考作品
- **Metroid / Castlevania: SOTN**：品类命名来源，定义能力门控 + 探索 + 回溯。
- **Hollow Knight**：现代银河城标杆——精妙地图、能力（冲刺/二段跳/下劈）双重价值、boss 设计、氛围叙事。小团队（Team Cherry 3 人）杰作。
- **Ori 系列**：移动手感天花板，把"移动能力"本身做成核心爽点 + 高品质演出。
- **Axiom Verge / Guacamelee**：理解能力门控的多样变体（Guacamelee 的维度切换是绝妙门控）。
- **Blasphemous**：银河城 + 魂类融合，黑暗美术风格。
- **Super Metroid**：地图引导设计的永恒教科书（不靠文字，靠环境引导玩家）。

## 常见坑
- **回溯（backtracking）变成枯燥的折返跑**：拿到能力后回头路太长、无新内容、无快速传送，疲劳感强。需传送点 + 捷径 + 沿途新内容。
- 玩家"迷路"——不知道该去哪、新能力能开哪里。地图标记 + 微妙的环境引导是解药。
- 能力获得顺序的门控逻辑出 bug（序列破坏 sequence break）或卡死（拿不到必需能力无法推进）。
- 地图设计平庸（线性伪装成探索），失去"互联豁然开朗"的核心魅力。
- 战斗手感或 boss 不过关（很多银河城含魂类战斗成分）。

## 单人/小团队可行性
**高，是小团队的明星品类**（Hollow Knight、Ori、Axiom Verge 一两人到几人完成）。纯单机、2D、轻数值，技术门槛适中。**最大成本与门槛是地图设计这门手艺**——一张优秀的互联地图需要反复打磨能力门控的编排与节奏，这是设计功力而非工作量。小团队建议：① 先确定 5-8 个核心能力及其门控顺序，画出地图拓扑骨架再填血肉；② 移动手感优先打磨（移动是玩家全程在做的事）；③ 强力的地图/标记 UI 降低导航挫败。美术风格统一性比体量更重要。
