# 大型多人在线角色扮演 (MMORPG)

## 核心循环
在持久的共享世界中：做任务/打怪升级 → 获得经验、装备、金钱 → 角色变强解锁新区域/副本 → 与其他玩家社交/组队/公会协作 → 满级后进入**终局循环（endgame：副本/团本/PvP/装备追求）**→ 长期养成与社交沉淀。核心是**"角色长期养成 + 持久世界的社交归属感 + 终局重复内容的追求"**。是为长留存（数月到数年）设计的品类。

## 关键子系统
- **角色养成**：等级、职业/天赋、技能、装备词条——长线成长是核心驱动。
- **任务系统**：主线（引导 + 叙事）+ 支线 + 日常/周常（留存钩子），是升级阶段的主体内容。
- **副本/团本 (dungeons/raids)**：多人协作 PvE，机制化 boss 战，是终局核心内容与社交粘合剂。
- **装备/掉落与追求**：稀有装备、词条、毕业曲线——满级后的核心追求。
- **社交系统**：组队、公会、交易、聊天、社交关系——MMO 的灵魂与留存壁垒。
- **PvP**（可选）：竞技场/战场/世界 PvP。
- **经济系统**：玩家间交易 + 拍卖行 + 货币产出/回收（防通胀的金币 sink）。
- **持久世界与服务器**：在线同步、世界状态、分服/跨服。

## 经济/数值要点
- **超长养成曲线**：经验/装备需求设计为数百小时的爬升，是订阅/留存的商业基础。曲线节奏（升级速度、装备门槛）直接决定留存与流失。
- **金币 sink（回收）是 MMO 经济的生死线**：玩家持续产出金币，必须有等量消耗渠道（修理/交易税/消耗品/高级商品），否则恶性通胀摧毁经济。
- **终局是真正的留存战场**：满级后靠副本轮换、装备追求、赛季、PvP 排名留人。endgame 内容枯竭 = 流失。
- 装备战力 scaling 与版本更新（资料片）的 power creep 需谨慎，避免旧内容/旧装备瞬间贬值伤害玩家。
- 付费模式（订阅/buy-to-play/F2P+商城）深刻影响数值松紧与设计取向。

## 经典参考作品
- **World of Warcraft（魔兽世界）**：品类标杆，任务引导 + 副本/团本 + 公会 + 资料片运营，定义现代 MMORPG 范式与终局循环。
- **Final Fantasy XIV**：叙事驱动 MMO + 职业自由切换 + 高品质团本，重生（A Realm Reborn）逆袭的运营典范。
- **Old School RuneScape**：技能向 MMO（无职业，练技能）+ 玩家驱动经济，长青的轻量化范式。
- **Guild Wars 2**：动态事件 + 去除传统"练级跑图"的设计实验，水平进度（horizontal progression）。
- **EVE Online**：玩家驱动的沙盒经济与政治，单一宇宙，证明 MMO 经济/社会系统的深度上限。
- **Lost Ark / 黑色沙漠**：理解 MMO 与抽卡/养成付费深度结合的现代东亚范式。

## 常见坑
- **内容消耗速度远超产出**：玩家几周吃光数月开发的内容，终局空虚则流失。MMO 是无尽的内容军备竞赛。
- 经济通胀失控（金币 sink 不足），破坏交易系统与新手体验。
- 升级阶段冗长枯燥（无意义的清怪跑腿），现代玩家容忍度低。
- power creep（资料片让旧内容/装备贬值），伤害老玩家积累。
- 冷启动死亡螺旋：MMO 需要活跃人口才有社交/组队/经济，没人则世界空荡，体验崩塌。

## 单人/小团队可行性
**极低，是对 solo/小团队最不友好的品类，强烈不推荐。** 几乎所有维度都是重负担的叠加：① 海量持续的内容产出（任务/副本/装备/区域）——MMO 是内容黑洞；② 持久世界的服务器架构、在线同步、防作弊、运维成本；③ 长期 LiveOps 运营（赛季/资料片/平衡/客服）；④ 经济系统设计与反通胀；⑤ **致命的网络效应壁垒**——没有玩家基数则社交/经济/组队全部失效，世界变鬼城。即便大厂做 MMO 也常年亏损。若小团队对 MMO 元素有兴趣，唯一务实方向是做**轻量在线/co-op RPG**（小规模联机、非持久世界，如 Valheim/星界边境思路）或**单机 RPG**，彻底放弃"大型持久 MMO"的目标。
