# MOBA (多人在线战术竞技)

## 核心循环
选英雄 → 分路对线（补刀攒钱攒经验）→ 用金钱买装、用经验升级技能 → 游走/gank/团战争夺地图资源（野怪/龙/塔）→ 滚动经济与等级优势 → 推塔 → 摧毁敌方基地。微循环=补刀/换血；中循环=一波 gank 或团战；宏循环=运营资源差推塔破高地。

## 关键子系统
- **英雄系统**：每英雄一套技能组（被动+多主动+大招），定位（坦/战/法/刺/射/辅），独特机制制造差异化。是内容与平衡的核心。
- **地图与资源**：三路 + 野区 + 中立目标（大小龙/Buff），视野（眼）系统决定信息博弈。
- **经济系统**：补刀/击杀/助攻/拆塔金钱，购物出装路线（核心装→大件）。
- **等级与技能加点**：经验曲线、技能升级顺序。
- **团队角色分工**：carry / 辅助 / 打野 / 上单的资源分配（谁吃线、谁让资源）。
- **元游戏 (meta)**：版本强势英雄/出装/分路体系，靠 patch 持续轮换。

## 经济/数值要点
- **金钱与经验差是唯一的硬通货**——所有机制（补刀、击杀赏金、目标）都在调控双方资源差的累积速率。
- **追赶机制（comeback）**：落后方击杀领先方有额外赏金（bounty），防止 15 分钟即定胜负的雪球死局。这是 MOBA 平衡的关键阀门。
- 技能数值需考虑成长（每级 +X）+ 装备加成的复合 scaling，前中后期强度曲线（早强晚弱 vs 大器晚成）是英雄定位的数值表达。
- 平衡是**永恒的版本工程**，没有"调完"，只有持续 patch 维持英雄/出装的多样性与胜率收敛。

## 经典参考作品
- **DOTA 2**：机制深度天花板（转身率、攻击前摇、信使、可控小兵、肉山），高技能上限，反补/拉野等独特经济操作。
- **League of Legends**：降低硬核度、强化英雄技能 combo 与节奏，季度版本+皮肤运营的商业标杆。
- **王者荣耀**：移动端适配（操作简化、对局时长压缩到 ~15 分钟），证明 MOBA 可大众化、碎片化。
- **Heroes of the Storm**：去掉补刀/装备，全队共享经验、多地图机制——验证"去经济化"团队向 MOBA 的可能与风险。
- **Deadlock (Valve)**：第三人称射击 + MOBA 融合，探索品类边界。

## 常见坑
- **平衡地狱**：英雄越多，平衡组合爆炸，永远有版本之子与下水道英雄。
- 新手门槛极高（机制、英雄池、出装、地图意识），劝退率高。
- 雪球失控（无追赶机制时早期优势直接锁死比赛）。
- 团队依赖导致的负面体验（队友坑、挂机、有毒交流），需配套行为系统。
- 对局过长（30-50 分钟）+ 一旦开局难以投降，时间成本高。

## 单人/小团队可行性
**极低，不推荐 solo/小团队作为完整品类。** 重负担：① 大量英雄设计与美术（每个都是独立技能组）；② 实时网络同步（低延迟、防作弊、断线重连）；③ 匹配/排位/反作弊系统；④ 持续的平衡运营与版本更新；⑤ 没有玩家基数则匹配为空，体验崩塌（网络效应壁垒）。若团队执意涉足，务必**极度缩小 scope**：更少英雄、更短对局、PvE 或异步、或只做某个子系统的创新（如 Deadlock 的 FPS 融合）。深度平衡问题可参考 moba-design-consultant 技能。
