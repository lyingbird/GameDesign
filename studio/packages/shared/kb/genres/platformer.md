# 平台跳跃 (Platformer)

## 核心循环
观察一段关卡布局（平台、缺口、陷阱、敌人）→ 规划路线 → 用跳跃/冲刺/抓墙等移动动作执行 → 失败（坠落/受击）即时重生 → 微调操作再试 → 通过这一段抵达检查点 → 进入引入新机制或更难编排的下一段。核心快感是**"移动本身的手感愉悦 + 攻克高难编排的精通感（mastery）"**——玩家在反复试错中把一段看似不可能的关卡内化成肌肉记忆。与银河城（metroidvania）不同：纯平台跳跃以**线性/关卡制的操作挑战**为核心，而非地图探索与能力门控。

## 关键子系统
- **角色移动手感（game feel）**：跳跃曲线、二段跳、冲刺、土狼时间（coyote time）、跳跃缓冲（jump buffering）、可变跳跃高度——这是平台游戏的灵魂，0.05 秒的参数差异决定"丝滑"还是"粘滞"。
- **关卡设计与编排**：每段关卡是一道"移动谜题"，把已教的动词组合成新挑战；难度通过编排密度而非数值堆叠递增。
- **检查点 / 重生节奏**：即时、零惩罚的重生（死亡→重来 < 1 秒）是硬核平台的根基，把挫败转化为"再来一次"的心流。
- **机制变奏层**：随关卡引入新动作或环境元素（移动平台、风、重力翻转、抓钩、墙跳），每个挖出多关变奏。
- **可选收集 / 计时**：隐藏收集品与速通计时（speedrun timer）提供精通后的二周目深度与社区竞速。
- **Boss / 高潮段**：把本章学到的所有移动动词压成一场综合考核。

## 经济/数值要点
- **典型为轻数值 / 无养成**——没有装备、等级或资源经济；"数值"几乎全在**移动参数与难度曲线的编排**上。
- 核心可调量：跳跃初速度与重力、冲刺距离/冷却、coyote/buffer 帧数、敌人/陷阱的判定框与时序——靠大量手感测试与逐帧迭代，而非公式推导。
- 难度曲线是真正的"数值设计"：新机制引入节奏、每段认知/操作负荷的递增量、送关与硬关的间隔；硬核平台（Celeste B/C 面、Super Meat Boy 暗黑世界）把曲线拉到极陡但以即时重生兜底。
- 命中判定务必**宽容**（玩家有利的判定框）以保证"是我操作失误"而非"游戏不公"的感受。

## 经典参考作品
- **Super Mario Bros. / Super Mario World**：平台跳跃的奠基与天花板，关卡即无言教学的范式。
- **Celeste**：精准平台 + 即时重生 + 辅助模式的现代典范，移动手感（冲刺/抓墙）打磨到极致，小团队（Extremely OK Games）杰作。
- **Super Meat Boy**：硬核精准平台 + 零惩罚秒重生，把"死亡上千次仍想再来"做成心流，两人团队作品。
- **Hollow Knight**：移动手感与平台挑战的标杆（虽偏银河城，其纯平台段如白宫值得对标）。
- **N++ / The End is Nigh**：极简机制 + 海量关卡编排深度，证明"一个好动词 + 精雕关卡"价值远超内容堆量。
- **Ori 系列**：把移动做成艺术（弹跳、冲刺连段），高美术产能的对照参考。

## 常见坑
- **手感不过关**：跳跃发粘、缺 coyote time/跳跃缓冲、判定框过严——玩家把失败归咎于游戏而非自己，直接劝退（这是平台游戏的头号死因）。
- **重生惩罚过重**：死亡后长读条/退回远处检查点，破坏"再来一次"的心流，硬核段尤其致命。
- **难度断层**：突然出现远超当前操作认知的硬段，且无可选辅助/跳过，卡死流失。
- **机制深度不足**：核心移动动词变奏空间小，几关后玩法被穷尽；或一次塞太多动作来不及教学。
- **美术产能陷阱**：追求 Ori 级演出但团队产能不足，内容量严重不足。

## 单人/小团队可行性
**极高，是 solo/小团队的经典优势品类**（Celeste、Super Meat Boy、N++、The End is Nigh 均为个人/极小团队作品）。技术门槛适中（2D、无联机、物理可自写一套简化跳跃模型而非依赖通用物理引擎——后者反而难调手感），美术可用像素风控制产能。**核心成本是手感打磨与关卡设计才智，而非工作量**。务实策略：① **先用一个白盒原型把跳跃/冲刺手感调到"光是移动就爽"再做任何关卡**（手感是地基，值得花数周）；② 自写跳跃控制器并暴露 coyote/buffer/可变跳高等参数便于逐帧调试；③ 关卡追求"每段教一个新维度"的无言教学 + 即时零惩罚重生；④ 加可选辅助模式（如 Celeste）扩大受众而不稀释硬核体验；⑤ 隐藏收集 + 速通计时低成本提供长尾深度。避免：依赖通用物理引擎硬调手感、做需要联机或重美术演出的大制作。
