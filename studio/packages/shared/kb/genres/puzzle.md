# 益智 / 解谜 (Puzzle)

## 核心循环
面对一个谜题/关卡 → 观察并理解规则与目标 → 尝试操作、推理、试错 → 找到解法的"啊哈！"顿悟 → 完成关卡获得满足 → 进入引入新变量/更难的下一关 → 规则理解逐步深化。核心快感是**"理解规则→破解谜题→顿悟（aha moment）的智力满足"**。乐趣来自思考本身，而非动作或数值。

## 关键子系统
- **核心机制 (the central mechanic)**：一个独特、可深挖的规则/动词（推箱子、传送门、时间倒流、连线消除…），整个游戏围绕它展开变奏——这是益智游戏的灵魂。
- **关卡设计与教学曲线**：每个关卡是一个精心构造的问题；通过关卡顺序"无言地教会"玩家机制的新维度（设计的最高工艺）。
- **难度曲线**：从教学（送分，建立直觉）→ 巩固 → 组合变奏 → 高难脑筋急转弯，平滑爬升。
- **提示/跳关系统**（可选）：缓解卡关挫败，平衡放弃率。
- **谜题类型**：逻辑（数独/推箱）/ 物理（割绳子）/ 空间（俄罗斯方块/传送门）/ 消除匹配（三消）/ 叙事解谜（密室/点击冒险）。
- **变体层**：消除类常叠加关卡目标、限制步数、特殊砖块等元素维持新鲜。

## 经济/数值要点
- **多数纯解谜是轻数值/无数值**——核心是"解法的优雅与难度梯度"，而非经济或养成。
- 关键"数值"其实是**难度曲线的编排**：新机制引入的节奏、每关认知负荷的递增量、送分关与卡关的间隔——靠测试与迭代而非公式。
- **消除/匹配三消类是例外**：常叠加 F2P 经济（体力/步数/道具/付费续命），关卡难度被刻意调控来引导付费（如卡关后买步数），是数值/付费设计密集的子类。
- 关卡的"解空间"设计：理想是有唯一或少数优雅解，避免暴力穷举或多解导致顿悟感稀释。

## 经典参考作品
- **Tetris（俄罗斯方块）**：永恒的机制纯度 + 难度自适应（速度递增），无关卡却无限耐玩，益智游戏的原点。
- **Portal / Portal 2**：传送门机制 + 关卡即教学的天花板，空间解谜 + 叙事，"无言教学"设计典范。
- **Baba Is You**：规则本身可被推动改变（meta 机制），创新性的逻辑解谜，小团队（一人起家）杰作。
- **The Witness**：连线机制的极致变奏 + 环境叙事，一个机制挖到极深的范例。
- **Candy Crush / 三消类**：理解消除匹配 + F2P 关卡经济/付费设计的商业范式。
- **Stephen's Sausage Roll / 推箱子类**：纯粹逻辑解谜的硬核深度上限。

## 常见坑
- **难度曲线断层**：突然出现远超当前认知的硬关，玩家卡死劝退（无提示/跳关则更致命）。
- 教学不足：玩家不理解机制规则就被丢进难题，挫败而非挑战。
- 机制深度不足：核心机制变奏空间小，几关后玩法被穷尽，新鲜感枯竭。
- 多解/暴力解破坏顿悟：玩家靠穷举而非理解过关，智力满足感丧失。
- 三消类付费墙过狠（恶意卡关逼氪），伤害口碑。

## 单人/小团队可行性
**极高，是 solo/小团队的理想品类之一**（Baba Is You、Patrick's Parabox、Stephen's Sausage Roll 均为个人/极小团队作品）。技术门槛低（多数 2D、逻辑驱动、无联机无复杂物理）、美术可极简。**核心成本是设计才智而非工作量**——一个绝妙的核心机制 + 精雕的关卡序列，价值远超内容堆量。小团队务实策略：① **找到一个有深度、可挖掘变奏的独特核心机制**（这是成败关键，值得花大量时间打磨原型）；② 关卡设计追求"每关教一个新维度"的无言教学；③ 用难度曲线 + 可选提示/跳关平衡挫败与成就；④ 警惕只有"花活"无深度的机制（玩几关就穷尽）。避免做需要联机或重运营的三消 F2P（那是另一套商业/数值密集的游戏）。
