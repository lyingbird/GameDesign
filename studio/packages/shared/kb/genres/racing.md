# 竞速/赛车 (Racing)

## 核心循环

选择载具/赛道/模式 → 开始比赛，通过转向/油门/刹车控制载具在赛道上行进 → 利用驾驶技巧（过弯、漂移、氮气/道具使用）超越 AI 或玩家对手 → 赛段结束记录名次/圈速 → 解锁奖励（新车/赛道/改装件）→ 调整载具配置或挑战更高难度/更快对手再次出发。快感核心分为两类：**街机型**注重"速度与操控的感官刺激+道具混战的随机乐趣"；**拟真型**注重"精准驾驶线、制动点与换挡节奏带来的技术精通感"。

## 关键子系统

- **驾驶手感（Vehicle Feel）**：转向响应速度、重量感、抓地力曲线、漂移触发与回正手感是竞速游戏的灵魂；街机型夸大操控响应（立即转向、夸张漂移）；拟真型模拟轮胎摩擦、重量转移、悬挂形变；两者之间的混合调校（如极限竞速地平线）是差异化难点所在。
- **物理模型**：街机物理（简化、可预测、无轮胎温度/磨损/油量变量）适合休闲竞速；拟真物理（轮胎物理模型 TM、空气动力学、载重转移）需大量工程资源，是独立团队最难啃的技术块；中间态（带漂移但不含轮胎温度模拟）是小团队的可行切入点。
- **赛道设计**：赛道是竞速游戏的关卡，需兼顾「可学习的驾驶线」（每个弯道有明确的最优路线）与「超车点」（直道尾/慢弯入口）；赛道宽度、弯道曲率、路面变化（上坡/�涉水/跳台）影响竞技公平性；开放赛道（如地平线的野外道路）需程序化生成或大量手工美术投入。
- **漂移与氮气/加速道具**：漂移（甩尾控制）是街机赛车的核心技巧表达，需设计独立的漂移物理参数（反打角度、漂移角度上限、修正扭矩）；氮气/超级加速道具提供策略节奏点（何时使用 N2O/蘑菇）；道具竞速（如马车）需额外设计道具平衡、投射物碰撞与干扰判定系统。
- **AI 与橡皮筋机制（Rubber-banding）**：AI 对手根据玩家领先差距动态调整速度（领先时 AI 加速追赶，落后时 AI 减速），保持比赛紧张度；过度橡皮筋让技术优势感消失导致玩家不满；弱橡皮筋则单人后期比赛变成独自跑圈；平衡点通常是对 AI 速度设定 ±5%–10% 动态范围，且对玩家碰撞后给予恢复缓冲而非直接速度提升。
- **载具改装与成长系统**：改装件（引擎/底盘/轮胎/外观）提供养成深度和个性化；数值改装需配合赛事分级（同类别竞技），否则 P2W 化破坏多人公平性；外观改装（涂装/贴纸/车身套件）是不影响平衡的商业化安全区。

## 经济/数值要点

- **载具性能分级**：通常以"PI 值"或"星级"对载具综合性能评分，并据此划分赛事等级，防止高性能载具碾压入门赛事；分级系统需对每项性能参数赋予权重并持续校准，是竞速游戏数值平衡的核心工作量。
- **改装数值增益**：每个改装件对应速度/加速/操控/制动四项基础参数的线性或非线性增益；增益上限需设置，防止最优载具配置单一化（meta 固化）；赛车游戏的数值深度远低于 RPG，但设计失误更显眼（如某改装使直道速度超过物理上限）。
- **拟真赛车的 DLC 经济**：车辆 IP 授权（保时捷、法拉利等）是主要成本，单车型授权费可达数万–数十万美元；Forza/Gran Turismo 将大量车辆放入赛季更新 DLC，以持续发布维持收入；独立团队应优先使用虚构车型或开源/CC 车型设计，规避授权风险。
- **多人竞速匹配**：ELO 或 Glicko 等段位机制需要足够的玩家基数才能有效运转，小体量发布时匹配质量差；建议初期采用开放大厅 + 时间试跑（Time Trial）排行榜作为多人替代，待社区规模成形后再引入段位系统。
- **移动端收费模型**：手机竞速常见免费下载 + 能量系统（限制每日比赛次数）+ 车辆礼包/抽卡；能量系统在竞速品类中争议极大，因为玩家期待"即时开局"；去掉能量系统改为直接付费解锁 DLC 车辆在口碑和长期留存上通常更优。

## 经典参考作品

- **马里奥卡丁车系列（Mario Kart）**：道具竞速街机赛车的绝对标杆；蓝龟壳/红龟壳的道具系统设计经历数代迭代，将"前排焦虑、后排翻盘"的戏剧张力做到极致；多人本地对战是品类最强社交场景。
- **Forza Horizon 系列（极限竞速地平线）**：开放世界竞速的现代标杆；拟真与街机手感混合调校（以 ForzaTech 物理引擎为基础加入可切换"街机辅助"）；赛季活动 + 大量 DLC 车辆的运营模式是主机竞速 live service 的参照。
- **Gran Turismo 系列**：拟真赛车模拟的历史沉淀；驾驶学校教学、赛车执照系统是新手引导的设计范式；GT7 的"创作者主义"理念将汽车文化内容（博物馆/摄影/音乐回放）融入游戏，拓展了品类的内容边界。
- **Trackmania**：纯时间试跑竞速 + 社区赛道编辑器的极简范式；去掉 AI/对手直接对抗，以"打破自己的纪录"为核心，证明纯技术挑战也能维持高度留存；低资产需求的赛道编辑器使社区内容爆发。
- **QQ飞车**：国内卡丁车竞速手游/端游的代表；将漂移操作游戏化（氮气积累机制）+ 赛车外观时装化（皮肤收入为主）的商业模式成功本土化；证明竞速品类在移动端可以用时装经济替代数值 P2W。
- **Forza Motorsport 系列**：闭路赛道拟真竞速，侧重赛道驾驶线精研和载具调校深度；与地平线互补定位（开放 vs 赛道），适合对赛车技术有执念的核心受众；Car Pass 订阅制 DLC 是持续运营收入模型参考。

## 常见坑

- **驾驶手感原型验证不足**：过早投入赛道美术和车辆建模，驾驶物理仍未打磨完成；竞速游戏的手感是核心，必须先用白盒赛道 + 简模载具把手感跑通，再进入资产制作。
- **橡皮筋机制过激**：单人赛事 AI 在玩家领先时追上速度明显快于物理上限，技术好的玩家反而输给最后弯道被 AI 超越，失去技术成就感，是中高难度单人赛事差评高发点。
- **赛道设计缺乏超车机会**：全弯道赛道无长直道或慢弯入口，极难超车，比赛退化成起跑位置决定论，AI 排位赛与正式赛成绩高度相关，玩家感受公平性差。
- **车辆 IP 授权纠纷**：使用真实品牌/车型外观未获授权，上架后面临下架或法律风险；即使购买短期授权也需考虑续约成本；独立项目应优先虚构车型或签订明确买断条款。
- **多人匹配基数不足**：小体量独立竞速游戏上线时玩家量不足以维持有效匹配，多人大厅长期空置，核心玩法无法验证；需提前设计离线 / AI 填充 / 异步排行榜作为过渡。
- **移动端输入方案不适配**：虚拟摇杆 + 虚拟按键的布局不适合竞速的高频操作，陀螺仪转向又在公共场所不便使用；需在 UI 设计期早期测试多种输入方案（陀螺仪/触摸滑条/虚拟方向盘），而非上线后修改。

## 单人/小团队可行性

**整体偏难，拟真方向尤其困难**。主要瓶颈：① 车辆与赛道 3D 资产量大，即使是中低精度赛车游戏也需要数十个高质量 3D 模型，单人美术产能严重受限；② 物理模型的精度与手感调校需要大量真实驾驶参考与多轮测试，拟真物理更需专项引擎研发能力（使用 Bullet/PhysX 需深度定制）；③ 车辆 IP 授权成本高，虚构车型设计需专业工业设计背景。**可行路径**：① **街机/卡丁车方向**是小团队最可行的切入点——简化物理（无轮胎温度、无空气动力学）、风格化低面数美术、5–8 条赛道起步；② **时间试跑 + 社区赛道工具**（参考 Trackmania 模式）——用户共创内容解决资产量瓶颈，团队专注于引擎手感与编辑器体验；③ **程序生成赛道**配合程序化环境美术可大幅降低内容产能压力。**务实建议**：先用 Unity/Unreal 现成车辆物理插件（如 Edy Vehicle Physics、Chaos Vehicles）快速原型验证手感，不要自研物理；用极简几何体赛道跑通核心手感循环后再投入资产制作；多人功能建议延迟到有稳定玩家基数后再开发，初期以 Time Trial 排行榜替代。
