# 音乐/节奏 (Rhythm)

## 核心循环

选择曲目与难度 → 随音乐节拍按照谱面提示输入操作（按键/点触/滑动/体感）→ 系统判定每个输入的时序精度（Perfect/Great/Good/Miss 等级别）→ 实时反馈（Combo 计数、分数跳动、视觉特效）→ 曲目结束显示成绩（准确率/Combo/Rank）→ 对比历史最佳 / 排行榜 → 选择更高难度或新曲目再次挑战。核心快感是**"身体与音乐同步的心流体验"**加上**"精通某首难曲的成就感"**——判定越精确、曲子越难，打出好成绩的满足感越强烈。

## 关键子系统

- **判定窗口（Timing Window）**：每个判定等级对应一个时间偏差范围（如 Perfect ±22ms、Great ±50ms）；窗口宽窄直接决定游戏难度曲线和上手友好度；过窄劝退新手，过宽失去精通深度。不同平台（移动/主机/PC）建议使用不同的窗口预设。
- **谱面设计（Chart Design）**：谱面是音游的核心内容单元，质量高低决定曲目体验；好谱面遵循音画同步（音符对应旋律或鼓点）、手型合理（无不可能的物理动作）、难度梯度清晰；谱师（charter）是小团队中最稀缺的专项技能。
- **难度分级系统**：通常为 3–10+ 档，从入门到极难（如 Lv.1–15 或 1–30）；每档需有代表性曲目形成"难度地图"，帮助玩家找到当前合适挑战；过度依赖单一高难曲目留住硬核圈而忽视入门难度会压缩受众。
- **Combo 与准确率机制**：连续不 Miss 累积 Combo 乘分或解锁特效；准确率（Accuracy）独立统计 Perfect 比例；部分游戏（如 Arcaea）将两者合并成单一分数，部分（如 osu!）分开展示；设计选择影响玩家的目标感（追分 vs 追 Full Combo vs 追 All Perfect）。
- **输入延迟校准（Offset Calibration）**：音频输出延迟、显示延迟、输入设备延迟三者叠加；必须提供手动 offset 校准工具，允许玩家输入正/负偏移毫秒值；缺少校准的音游在不同硬件上体验严重不一致，是差评高发点。
- **排行榜与社区**：全球/好友排行榜是核心留存驱动；谱面评级（PP 系统如 osu!）为高分玩家提供长期目标；自定义谱面上传社区（如 osu! Beatmap、Friday Night Funkin' 的 mod 生态）可将产品从游戏变为平台。

## 经济/数值要点

- **曲库授权成本是最大变数**：正版音乐授权费从数百到数万美元/曲不等，且通常按平台、地区、时限分开授权；超出授权期或地区需下架曲目，会严重损害玩家信任（如 Beat Saber 的部分曲包下架事件）。原创音乐或 CC 协议音乐（如 osu! 大量社区原创曲）可绕开授权成本，但获客力弱于知名 IP。
- **曲包 DLC 定价**：主流模式为基础游戏含若干免费曲 + 付费曲包（每包 3–10 曲，约 2–8 美元）；或订阅制（月卡解锁全曲库）；零售包（买断全曲库）适合主机渠道；移动端常见免费下载 + 单曲解锁或 VIP 订阅。
- **难度与谱面数量**：每首曲目至少提供 3–4 个难度（Easy/Normal/Hard/Expert），每个难度都需独立制谱，内容产出成本按曲目数 × 难度数线性增长。
- **分数通货膨胀**：新谱面出率越高，旧谱面排行的参考价值越稀释；若使用 PP 类动态评分（如 osu!），需要持续维护星级评定算法保证新老谱面难度锚定一致。
- **平台差异化**：PC 键盘（osu!mania）、PC 鼠标/平板（osu! standard）、移动触屏（Cytus/Arcaea）、VR 体感（Beat Saber）、街机控制器（太鼓达人）各有不同的判定窗口基准和输入特性，跨平台移植需独立调校，不能共用同一套参数。

## 经典参考作品

- **osu!**：免费 PC 音游平台的教科书；用户自制谱面生态使曲库近乎无限，PP 排名系统提供长期成长感；其开源精神和社区驱动模式是小团队绕开授权成本的最佳参照。
- **Beat Saber（VR）**：将音游与 VR 体感结合的突破性设计，谱面视觉化直观，自定义谱面 mod 社区活跃；证明新硬件平台为音游打开细分市场的可能性。
- **Cytus / Cytus II（移动）**：移动触屏音游音画结合设计的标杆，扫线判定机制独创；高质量原创与授权曲库；证明移动端音游可以达到主机级制作水准。
- **Arcaea（移动）**：引入空间（地面+空中双轨道）和弧线滑条，拓展了触屏音游的表达维度；动态难度评分（cc 值）和玩家潜力值（ptt）系统为核心玩家提供长期量化目标。
- **太鼓达人（Taiko no Tatsujin）**：街机 + 主机双平台的经典；单一输入（鼓面/鼓边）极度简化但节奏设计精深；国内联动版本证明街机音游本土化运营的可行性。
- **Friday Night Funkin'（FNF）**：低成本开发 + 完全开放 mod 社区的病毒式成功案例；简单的下落式判定 + 强烈的视觉风格，社区贡献了数千张自制谱面；证明"平台化"策略能以极低成本获得海量内容。

## 常见坑

- **输入延迟未校准**：发布时未提供 offset 调节，不同显示器/音频设备的延迟差异使判定感受天差地别，音游类差评的首要来源。
- **难度断崖**：Easy 太简单、Normal 直接跳到高难，中间难度缺失，大量中级玩家找不到适合的挑战点即流失。
- **谱面质量参差不齐**：曲目数量追求但谱面对音不准、手型反人类或难度标注不实，玩家对"烂谱"的容忍度极低，差评连带拉低整游戏评分。
- **授权曲目下架**：上线时购买短期授权，到期后被迫下架热门曲目，严重损害玩家信任；买断前未充分评估授权成本上限，导致运营中期陷入法律纠纷。
- **移动端触屏判定漂移**：触屏坐标与游戏判定区域之间的像素偏移未校准，特别是在非 16:9 屏幕或刘海屏上出现系统性判定偏差。
- **缺乏社区工具**：不提供谱面编辑器或自定义导入通道，核心玩家创作需求无处释放，游戏生命周期随官方曲库更新节奏快速衰减。

## 单人/小团队可行性

**中等可行**，但依赖路线选择。纯引擎技术门槛不高（判定系统、音符下落渲染，1–2 人可实现原型），美术风格化可控制产能。**核心挑战有两个**：① 曲库成本——若选授权音乐，需预算法务与版权费；推荐路线是使用 CC/原创音乐 + 向社区开放谱面制作（如 FNF 模式）；② 输入延迟校准需要在多设备真机测试，远程测试难以覆盖，需要投入专项 QA 资源。**务实策略**：① 先用 5–10 首原创/CC 曲确立核心手感与视觉风格 → ② 开放谱面编辑器让社区贡献内容 → ③ 逐步以付费曲包或授权 DLC 补充商业曲库；② 移动端注意全面屏适配与多设备 offset 测试；③ 提供可视化 offset 校准界面（视频闪烁 + 音频 beep 对齐法），这是玩家最低容忍线。避免：在缺乏谱师的情况下冒险使用授权热门 IP 曲目，版权纠纷会让产品在上线期直接面临下架风险。
