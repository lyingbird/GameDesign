# 模拟经营 (Simulation / Management)

## 核心循环
观察当前状态（生产/财务/满意度）→ 做管理决策（建造、定价、雇人、研发、布局）→ 系统模拟运转产生结果（收入、产出、问题）→ 用利润再投资扩张/优化 → 解决涌现的瓶颈与危机 → 规模与复杂度螺旋上升。核心快感是**"优化复杂系统、让自己搭建的机器越转越顺、看着它成长的掌控感与心流"**。

## 关键子系统
- **生产/供应链系统**：原料→加工→产出的链条，瓶颈分析与流程优化（工厂/餐厅/农场的核心）。
- **经济/财务系统**：收入、成本、定价、现金流、贷款——经营的命脉。
- **实体管理**：员工（雇佣/技能/薪资/满意度）、顾客（需求/满意度/流量）、设施（建造/维护/升级）。
- **空间布局**：建筑/工位/动线的摆放优化（影响效率，常是核心 puzzle 层）。
- **研发/解锁树**：新产品/技术/建筑的解锁，提供长期目标。
- **事件/挑战系统**：随机事件、竞争对手、危机（避免纯优化变得枯燥）。

## 经济/数值要点
- **核心是一套自洽的经济模拟**：源（收入产出）与汇（成本损耗）的动态平衡，需形成可优化但不可轻易"无限钱"的闭环。
- **瓶颈设计**：好的模拟经营总有"当前最痛的瓶颈"驱动玩家行动（产能不足→扩产→现金流紧张→定价→满意度下降…），瓶颈的轮转就是节奏。
- 边际收益递减 + 复杂度递增：规模扩大后管理难度上升，制造"优化空间"。
- 平衡难点：避免"找到最优解后无脑滚雪球"（正反馈失控）——需持续引入新变量/危机/天花板。
- 数值需大量模拟/电子表格验证（产出率、回本周期、增长曲线）。

## 经典参考作品
- **Factorio**：自动化供应链巅峰，"我搭建的工厂自己运转"的心流天花板，瓶颈优化 + 异步生产的设计典范。
- **RollerCoaster Tycoon / Planet Coaster**：主题公园经营，布局 + 顾客满意度 + 财务，模拟经营经典范式。
- **Two Point Hospital / Theme Hospital**：幽默包装 + 房间布局 + 流程管理，轻松向经营标杆。
- **Stardew Valley**：农场经营 + 生活模拟，单人开发者（一人）现象级成功，证明品类的 solo 可行性。
- **Game Dev Tycoon / Software Inc**：抽象化的"做游戏/公司"经营，小团队友好的轻量模拟。
- **Dwarf Fortress / RimWorld**：殖民地模拟，涌现式叙事 + 深度系统交互的硬核方向。

## 常见坑
- **优化到头就无聊**：找到最优解 + 钱多到溢出后失去目标。需持续的新瓶颈/危机/解锁注入。
- 系统过于复杂导致新手劝退（信息过载、UI 不友好）——模拟经营的 UI/数据可视化是刚需。
- 经济失衡：要么前期太难（资金链断裂劝退），要么中期无限钱（失去张力）。
- 数值未充分模拟验证，回本周期/增长曲线失调。
- 微操疲劳：要求玩家手动管理过多琐事，缺乏自动化/批量操作。

## 单人/小团队可行性
**高，且有标志性 solo 成功案例**（Stardew Valley 一人、Factorio/RimWorld 小团队）。逻辑/系统驱动，美术可 2D/简约，无实时联机压力。**核心成本不是美术或技术，而是经济系统的设计与平衡调优**——需要大量模拟和迭代让系统"自洽且耐玩"。小团队建议：① 抓住一个清晰的"心流核心"（搭建/优化/经营的某个爽点）做深，而非堆砌系统；② 强力的数据可视化/UI（让玩家看懂瓶颈）是体验关键；③ 用电子表格/模拟脚本验证经济曲线；④ 引入轻量事件/解锁维持长期目标，防止"最优解后无聊"。题材包装（农场/医院/工厂/魔法）是低成本差异化。
