# 魂类 (Soulslike)

## 核心循环
谨慎探索 → 遭遇敌人，观察并学习其攻击模式（telegraph）→ 用耐力管理攻防（攻击/格挡/闪避/弹反）→ 击败敌人获得"魂"（货币/经验）→ 在篝火/检查点消费升级、回满补给 → 推进至 boss → 反复试错记忆 boss 招式直至通关。核心是**"观察-学习-精通"的硬核技巧循环 + 死亡惩罚带来的紧张感与战胜后的成就感**。

## 关键子系统
- **耐力系统 (stamina)**：攻击/闪避/格挡消耗耐力，逼迫玩家克制、把握攻防节奏——是魂类战斗的根本约束。
- **敌人/Boss 设计**：清晰可读的攻击前摇（telegraph）+ 攻击间隙（窗口期）。boss 是品类的核心内容与卖点，每个都是一场"考试"。
- **死亡惩罚系统**：死亡掉落魂（货币），需返回死亡地点拾回，再死则永久丢失——制造高张力。
- **检查点 (篝火/bonfire)**：休息回血但刷新敌人，分布即关卡节奏。
- **关卡设计**：连通的世界 + 捷径解锁（关闭后通向篝火的近路），探索即奖励。
- **属性/装备养成**：等级（加点）、武器/盾/法术、负重影响翻滚——轻度 RPG 层。

## 经济/数值要点
- **核心货币（魂/血/卢恩）双重身份 = 经验 + 货币**：升级和买装备共用一种资源，制造"花在哪"的取舍与死亡丢失的痛感。
- 难度不靠数值碾压，而靠**攻击模式复杂度 + 容错窗口收窄**。boss 伤害高（两三下致命）逼迫精准操作，而非堆 HP 海绵。
- 升级曲线：每级所需魂递增，玩家通过"刷魂"可一定程度软化难度（数值兜底），但核心仍是技巧。
- 武器伤害与属性需求（力/敏/智/信）挂钩，构成 build 取向，但不喧宾夺主。

## 经典参考作品
- **Demon's Souls / Dark Souls 系列**：From Software 奠基之作，定义耐力战斗、篝火、死亡找尸、互联关卡。
- **Bloodborne**：去盾强攻，"回血反击"（rally）机制鼓励侵略性，节奏更快。
- **Sekiro**：弹反（架势条）为核心，把魂类推向节奏动作/韵律方向。
- **Elden Ring**：开放世界化 + 召唤/灵魂帮手降低门槛，让魂类大众化破圈。
- **Hollow Knight**：2D 魂类 + 银河城，证明小团队可做出高品质魂味（耐力以外的容错设计）。
- **Lies of P / Nioh**：理解魂类的弹反/装备 build 等变体方向。

## 常见坑
- **难度=不公平**：玩家死亡若感觉是系统不讲理（看不清前摇、镜头吃屎、判定模糊）而非自己失误，则挫败而非成长。"难但公平"是铁律。
- boss 攻击模式不可读（无 telegraph、连段无间隙）→ 体验崩塌。boss 是品类成败核心。
- 死亡惩罚过重导致劝退，或过轻失去张力。
- 关卡缺乏捷径/连通感，跑图惩罚过长。
- 战斗手感（打击感、判定、翻滚无敌帧）不过关——魂类的命门。

## 单人/小团队可行性
中等，且有成功先例（Hollow Knight、Salt and Sanctuary、Blasphemous 均为小团队 2D 魂类）。纯单机无联机负担。**核心成本与门槛在战斗手感打磨 + boss 设计**——这是工艺活，需大量迭代。小团队建议：① 走 **2D/2.5D** 大幅降低动画与场景成本；② 把资源集中在**少量但精雕的 boss**（boss 质量 > 数量，玩家记住的是 boss）；③ 攻击前摇/判定帧/无敌帧的反复调试是重中之重。互联关卡 + 捷径设计能用较少场景制造"大世界"错觉，性价比高。
