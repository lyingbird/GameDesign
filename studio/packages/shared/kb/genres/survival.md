# 生存 (Survival)

## 核心循环
管理生存需求（饥饿/口渴/体温/健康）→ 采集资源（砍树/挖矿/狩猎）→ 制作工具与装备（crafting）→ 建造庇护所与基地 → 探索更危险区域获取更高级资源 → 应对威胁（怪物/天气/其他玩家）→ 装备与基地升级，生存能力螺旋上升。核心快感是**"从赤手空拳的脆弱到武装自给的成长 + 对抗环境的紧张感 + 沙盒创造自由"**。

## 关键子系统
- **生存需求系统 (survival meters)**：饥饿/口渴/体温/体力/健康等仪表，持续衰减制造压力——是品类的根本驱动。
- **采集与资源**：可采集的世界资源（节点/动植物/矿物），是一切的起点。
- **制作系统 (crafting)**：配方树，从原料到工具到高级装备/建筑，进度即配方解锁。
- **基地建造 (base-building)**：庇护所、防御工事、功能设施（熔炉/工作台），安全感与生产力的来源。
- **威胁系统**：敌对生物、夜晚、天气/季节、饥饿——压力源。可叠加 PvP（多人生存）。
- **探索/世界**：开放世界，危险与资源正相关，驱动外出冒险。
- **昼夜/天气循环**：节奏与威胁的周期性来源。

## 经济/数值要点
- **核心是衰减 vs 补充的速率平衡**：需求衰减速率 vs 资源获取/制作效率，决定生存的紧张度。太松则无压力，太紧则劝退。
- 资源稀缺度分层：基础资源易得（保证不卡死），高级资源稀缺/危险（驱动探索与冒险）。
- 制作配方的**资源成本曲线**：高级装备的材料需求逐级提升，构成"科技/装备进度"的数值阶梯。
- 早期生存压力大（脆弱），中后期度过生存门槛后转向建造/探索/优化——压力曲线需从"求生"平滑过渡到"发展"，否则后期失去张力。
- 多人生存还需考虑 PvP 平衡与基地防御/突袭的成本对抗。

## 经典参考作品
- **Minecraft**：生存 + 沙盒建造的现象级标杆，方块世界 + 自由建造 + 探索 + 生存模式，创造力天花板。
- **Don't Starve**：硬核生存 + 独特美术，理智/饥饿/季节多重压力，单局 roguelite 化的生存设计。
- **Subnautica**：海洋探索生存，恐惧 + 制作 + 叙事融合，单人生存叙事典范（小团队佳作）。
- **Valheim**：北欧生存建造 + boss 推进，小团队（Iron Gate 5 人）现象级成功，生存 + 进度节奏标杆。
- **Rust / ARK**：多人 PvP 生存，基地突袭 + 部落对抗，理解多人生存的硬核与负担。
- **The Forest / Green Hell**：第一人称生存恐怖，沉浸式生存机制。

## 常见坑
- **生存需求变成繁琐杂务**：频繁吃喝管理若无趣味则只是烦人。需让生存压力服务于探索/决策而非纯打断。
- 前期太残酷（反复饿死/被杀）劝退，或度过门槛后彻底无压力变空虚（压力曲线断层）。
- 内容深度不足：采集-制作-建造循环若无新目标/威胁/区域注入，几小时后枯竭。
- 多人生存的 PvP 突袭挫败（辛苦建的基地被夷平），需机制缓解（离线保护等）。
- 开放世界 + 多系统 = 巨大的内容与技术体量（世界生成、AI、物理、联机）。

## 单人/小团队可行性
**中等，高度依赖 scope 控制**。开放世界 + 多人 + 沙盒建造是巨大体量（Valheim 都耗时多年），但**单人/小型生存 + 聚焦设计**完全可行（Subnautica、Don't Starve 是小团队佳作）。小团队务实策略：① **避免开放大世界 + 多人 PvP**（两个最大无底洞）——做单人、半开放、或叙事驱动的生存；② 用**程序生成或紧凑手工世界**控制内容；③ 把生存压力设计成服务于核心体验（Subnautica 的恐惧驱动探索）而非纯杂务；④ 控制制作树/建造系统的复杂度。Don't Starve 的"roguelite 化生存"（单局制、随机世界）是用随机性换内容量的好思路。
