# 塔防肉鸽 (Tower Defense Roguelite)

## 核心循环
开局（run）→ 一关接一关抵御波次（塔防战斗）→ 每关/每波后从**随机给出的塔/词条/升级中三选一**进行局内构筑 → 围绕抽到的核心机制滚雪球 build → 通关或失守（roguelike 重开）→ 带永久解锁开下一局。核心快感是**"塔防的布局策略 + 肉鸽的随机构筑发现"双重叠加 + 每局长出不同的塔体系**。

## 关键子系统
- **塔防战斗核心**：放置/升级防御单位、波次进攻、路径/格位（见 tower-defense 卡）。
- **局内随机构筑 (roguelite draft)**：每关提供随机的塔解锁 / 全局词条 / 塔强化三选一。这是与传统 TD 的本质区别——**新意来自每局随机组合而非固定关卡内容**。
- **协同系统 (synergy)**：塔与词条之间的组合爆发（如"毒塔 + 毒伤翻倍词条 + 减速延长中毒时间"成型），是重玩性灵魂。
- **风险-回报抉择**：精英波换稀有词条、诅咒换强化——肉鸽式赌博。
- **元进度**：永久解锁新塔池 / 起始词条 / 新地图，决定死亡的意义。
- **程序化关卡/波次**：随机地图布局或随机波次成分，增加每局变数。

## 经济/数值要点
- **双重经济**：① 局内即时金钱（建塔/升级，关卡内花光）；② 局内构筑资源（三选一的词条/塔，跨关累积成 build）。
- 难度（波次总 HP）随关卡指数 scaling，与玩家**构筑成型速度竞速**——build 滚起来就碾压，没起来就被淹没（典型肉鸽节奏）。
- 词条多为**乘区叠加**，极易失控（几个乘区相乘一关清屏），需独立乘区/上限 + 让"统治组合"稀有可遇不可求。
- 三选一的**抽取池设计**是关键：保证每次都有"诱人但需取舍"的选项，避免出现明显废牌或必选项。

## 经典参考作品
- **Isle of Arrows**：塔防 + 拼图式建造 + roguelite，每回合抽随机地块/塔，把 TD 与构筑/解谜缝合，小团队精品，值得参考。
- **Rogue Tower**：极简塔防肉鸽，随机路径生成 + 塔升级三选一，证明核心循环的极低成本可行性。
- **Vampire Survivors（广义参考）**：虽是幸存者类，但"每级三选一武器/被动 + 协同进化"的构筑滚雪球结构，与 TD-roguelite 的 build 逻辑高度同源，值得借鉴其多巴胺节奏。
- **Bloons TD 6（构筑参考）**：塔的多路升级与协同的深度，可为 roguelite 词条池提供设计素材。
- **Kingdom Rush + 肉鸽 mod 思路**：理解经典 TD 加随机构筑层的改造方向。

## 常见坑
- **继承塔防 + 肉鸽双方的坑**：既可能出现"统治塔/统治组合"（策略坍缩），又可能随机性不公平（开局没核心词条就摆烂）。
- 三选一选项设计差：常出现明显最优或全是废牌，构筑决策失去意义。
- 词条乘区失控，中段就 break 游戏，后期无张力。
- 局内 build 与塔防布局两层若割裂（词条不影响布局策略），则深度流于堆数值。
- 单局过长削弱"再来一局"的轻快感（TD 本就偏慢，叠肉鸽更需控制时长）。

## 单人/小团队可行性
**极高——是对单人开发者的明星推荐方向**（核心系统可控、新意来自每局随机构筑、不用一上来做巨量内容）。它把塔防的可控核心系统与肉鸽的"用随机性换内容量"结合，**用构筑组合的爆炸空间替代手工关卡的工作量**，对 solo 极友好。建议：① 先做扎实的小塔防核心（~6-8 塔 + 抗性矩阵）；② 加一层"每关三选一"的词条/塔池，重点设计**塔与词条的协同**（少而精、能两两生火）；③ 写模拟脚本验证 build 滚雪球曲线，防止乘区失控；④ 用程序化关卡/波次进一步压缩内容成本。
