# 塔防 (Tower Defense)

## 核心循环
放置/升级防御单位 → 敌人按波次沿路径进攻 → 用波间金钱再投资（建塔/升级/技能）→ 应对更强波次 → 通关或失守。核心动词是**预判 + 布局 + 资源再投资**。关卡内是"边打边规划"的微循环（看下一波预告 → 调整布防），关卡外是"解锁新塔/天赋"的宏循环。

## 关键子系统
- **塔/单位系统**：每种塔的攻击类型（单体/AOE/穿透/减速/毒/范围光环）、射程、攻速、优先级（最近/最远/最强/血量最高）。塔之间要有明确分工与协同（减速塔放慢，AOE 塔收割）。
- **敌人系统**：移动型/飞行/护甲/高血量 boss/分裂/治疗/隐身等抗性矩阵，逼玩家组合应对。
- **路径与地形**：固定路径（经典 TD）vs 自由摆放迷宫（maze TD，塔本身就是墙）。地形格位、高低差、可放置区限制是核心策略空间。
- **波次设计 (wave design)**：节奏曲线、混编波、boss 波、提前预告下一波成分。
- **经济系统**：击杀掉钱/波结算/利息机制；建造 vs 升级 vs 留钱的取舍。
- **元进度**：关卡解锁、塔科技树、天赋、难度模式（如循环无尽）。

## 经济/数值要点
- 核心张力是**有限金钱在"铺数量 vs 堆质量（升级）"之间的分配**。升级曲线常用指数成本 + 次线性收益，制造边际递减，逼玩家横向扩张。
- 敌人血量/赏金随波次增长须与玩家理论 DPS 增长**同步**——否则要么轻松碾压要么必死墙。做一张"波次 i 的来袭总 HP vs 玩家在该时点的可达 DPS"对照表来校准。
- 漏怪惩罚（生命值）要让失误可感知但前期可容错（如起始 20 命）。
- 注意**"防火墙"难度墙**：某一波突然超标会卡死玩家，需平滑。

## 经典参考作品
- **Plants vs Zombies**：题材包装 + 阳光双资源（采集+消费）把硬核 TD 大众化；植物分工清晰，关卡引入新机制的节奏教科书级。
- **Bloons TD 6**：塔的三向升级路径（每塔选一条主升+两条辅）提供极深 build 多样性；猴塔协同与"农场塔"经济流。
- **Kingdom Rush**：四类基础塔 + 英雄 + 主动技能（增援/陨石），手动技能给固定路径 TD 加操作维度。
- **Defense Grid**：纯净的资源再投资循环与塔重定位（拆塔回收）设计。
- **Dungeon Warfare / Orcs Must Die**：第三人称/陷阱向 TD，玩家亲自参战，模糊 TD 与动作边界。

## 常见坑
- **存在"统治塔"（dominant strategy）**：某塔/某组合性价比碾压所有，策略坍缩。需横向平衡与抗性逼迫多样化。
- 波次难度不平滑，出现劝退墙或后期"放置即赢"的真空。
- 信息不透明：玩家看不到塔的实际 DPS/射程，无法做明智决策。射程预览、伤害数字是刚需。
- 升级与新建的收益不可比，玩家算不清账。
- 无尽模式后期纯比拼数值堆叠，策略消失。

## 单人/小团队可行性
极高，是独立团队首选品类之一。核心系统（塔、敌人、波次、寻路）有限且可控，美术可走 2D/低多边形，无需海量内容。**新意可来自机制而非内容量**：自由摆放迷宫、塔进化、Roguelite 构筑（每局随机可选塔池/词条）是低成本高新鲜度的方向。建议先做 5-8 种塔 + 5-6 种敌人 + 一套抗性矩阵打磨手感，再横向加内容。寻路（A*/流场）与攻击目标选择是主要技术点。
