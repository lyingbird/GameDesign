# 回合制战棋 / 战术 (Turn-Based Tactics / SRPG)

## 核心循环
在网格战场上轮流行动 → 每回合移动单位、占据有利地形、发动攻击/技能 → 利用站位、掩体、行动点（AP）做最优决策 → 击败敌人完成战斗目标 → 战斗间隙养成单位/管理小队 → 推进战役。核心快感是**"深思熟虑的战术博弈 + 一步妙招扭转战局的智力满足"**。决策慢而重，每一步都可算。

## 关键子系统
- **网格与移动**：方格/六边形战场，移动范围、地形消耗、高低差影响视野/命中。
- **行动点系统 (AP / action economy)**：每单位每回合的行动预算（移动 + 攻击 + 技能），是战术决策的核心约束。
- **站位与掩体**：侧翼/背刺加成、掩体减伤、范围技能、控制区（zone of control）——位置即战术。
- **命中/伤害规则**：命中率（含地形/距离/侧翼修正）、暴击、护甲——XCOM 式概率 vs 火纹式确定性。
- **单位养成 / 职业系统**：升级、职业转换、技能树、装备——战斗外的 build 层。
- **关卡/任务设计**：地图布局、敌人配置、胜利条件（歼灭/护送/坚守/到达），是核心内容。
- **永久死亡（可选）**：单位阵亡不可逆（XCOM/火纹经典模式），抬高决策权重。

## 经济/数值要点
- **行动经济（action economy）是核心数值**：谁的有效行动多谁赢。围杀、控制（眩晕/减速=偷对方行动）、AOE（一打多）本质都在操纵双方行动数差。
- 命中率系统的体验权衡：概率（XCOM，刺激但"95% miss"令人崩溃）vs 确定（高级火纹，可精算）。若用概率，需"隐藏保底/连续 miss 补偿"缓解挫败。
- 敌我强度曲线：关卡难度靠敌人数量/质量/地形/目标，而非单纯堆数值。
- 养成数值（升级成长、职业加成）需与关卡难度曲线咬合，避免练度碾压或卡关。

## 经典参考作品
- **XCOM / XCOM 2**：掩体 + 命中率 + 永久死亡 + 基地经营双层结构，现代战术标杆，紧张感设计典范。
- **Fire Emblem（火焰纹章）**：兵种克制 + 永久死亡 + 角色羁绊叙事，确定性命中（高难）的 SRPG 经典。
- **Into the Breach**：完全信息（敌人行动完全可见）+ 极简 8x8 棋盘，把战棋纯化为"完美信息解谜"，小团队（Subset Games）杰作。
- **Final Fantasy Tactics / Tactics Ogre**：深度职业系统 + 叙事，SRPG 养成天花板。
- **Wargroove / Advance Wars**：剪刀石头布兵种 + 关卡设计，轻量化战棋。
- **Bad North / 陷阵之志变体**：理解极简化战术的可行性。

## 常见坑
- **概率挫败**：高命中率却 miss 的负面体验极强烈（"XCOM 时刻"），需保底机制或改用确定性。
- 单位/职业平衡失衡，出现"无脑最优单位"，战术多样性坍缩。
- 关卡设计偷懒（纯堆敌人数量/属性），缺乏地形与目标的巧思，沦为数值消耗。
- 养成碾压：练度足够后战术无关紧要，或反之卡关逼刷级（节奏破坏）。
- 回合过长（单位太多、动画太慢），战斗冗长。

## 单人/小团队可行性
**高，是 solo/小团队的优秀选择**。纯单机、回合制（无实时同步压力）、可 2D、技术门槛低（核心是网格逻辑 + 规则系统，无需复杂物理/网络）。Into the Breach 证明：**用极简规则 + 完全信息 + 精巧关卡可做出深度而无需海量内容**。小团队建议：① 优先考虑**确定性或低随机**规则（更易测试平衡、玩家更易上头）；② 用程序生成或紧凑手工关卡控制内容成本；③ 把设计精力投在"行动经济 + 站位"产生的涌现式战术上，而非单位数量。关卡/敌人配置的平衡调试是主要工作量。
