# 视觉小说/文字冒险 (Visual Novel)

## 核心循环

阅读文本与对话（角色立绘 + 背景场景 + 配音）→ 在分支节点做出选择（对话选项/行动决策）→ 选择影响好感度、旗标（flag）或剧情分支变量 → 进入对应分支线路继续阅读 → 积累特定条件后解锁特定结局（角色线 / 真结局 / 坏结局）→ 存档回溯选择不同分支（周目制）→ 逐步解锁全部结局与 CG 图鉴。核心体验是**"沉浸于故事与角色情感 + 主动探索叙事可能性"**——玩家既是读者也是参与者，分支结构将线性阅读转化为"叙事迷宫探索"，全收集（true end 解锁）成为内在动机；区别于纯文学的关键在于选择的能动感与 CG/配音带来的视听情感放大。

## 关键子系统

- **分支叙事与旗标系统（branching / flag）**：故事由布尔旗标（flag）和数值变量（好感度、属性值）驱动分支；选择节点改变旗标或好感度，后续内容检测这些值决定走向；设计需避免"蝴蝶效应"型复杂度爆炸——大多数商业作品采用主线单轨 + 角色线分支的树形结构，而非网状分支。
- **好感度/亲密度系统（affection / route lock）**：恋爱类 VN 中对目标角色的好感度累计决定进入哪条角色线；通常通过关键节点的选择加减分，到达阈值触发路线锁定；设计清晰的"路线锁定点"（route lock）提示避免玩家因不明原因跑错线而沮丧。
- **多结局结构（multiple endings / true end）**：作品通常设置若干普通结局、若干坏/BAD 结局以及解锁条件更严苛的真结局（true ending）；真结局往往要求通关其他角色线或收集特定旗标，制造全作通关的成就感；弹丸论破等作品更以第一视角真相揭露作为真结局的叙事高潮。
- **演出系统（presentation）**：立绘（差分表情 + 服装）、背景、CG（高精度事件插图）、语音（角色全配音 / 主要场景配音）、BGM 与音效、转场特效共同构成演出层；演出质量对情感沉浸的影响远超文本量，是区分商业作品与同人作品的主要分层维度。
- **文本系统（ADV vs NVL 模式）**：ADV 模式（下方文本框 + 立绘 + 背景）是主流；NVL 模式（全屏文字，接近小说排版）适合高密度内心独白或小说风叙事；日式商业 VN 多以 ADV 为主、重要场景切 NVL；文本跳过（skip read/unread）、回退（backlog）、自动播放（auto mode）是基础 UI 要求。
- **存档与回溯（save / load / backtrack）**：玩家依赖多存档槽与快速存档在关键选择前存档，以便回溯探索不同分支；部分作品提供内建"场景回放"或"章节选择"功能降低多周目摩擦成本，这对鼓励全结局收集至关重要。

## 经济/数值要点

- **文本量是最大成本驱动**：商业 VN 的总字数通常在 5 万字（短篇）到 50 万字以上（多线大作）；全配音方案下声优成本与文本量成正比，是发行预算的最大变量；独立制作常采用主角无声、支线角色部分配音的折中策略。
- **CG 数量与成本**：CG 是玩家直接感知的"里程碑奖励"；商业作品每条角色线通常配置 5-15 张高质 CG；独立作品可以立绘差分 + 背景合成替代手绘 CG，但全作 CG 数量直接影响玩家对内容量的感知价值。
- **立绘与差分规划**：一个角色通常需要多套表情差分（6-15 种）以覆盖对话情感变化；若角色数量多且每人差分充足，美术生产量可超预期；早期应规划角色数量上限与差分规格，避免后期美术产能超支。
- **多周目留存成本**：鼓励多周目的设计（真结局 / 全 CG 收集）可以用极低的额外内容成本换取更高玩家时长，但前提是分支结构有足够差异度，纯文字变化不足以驱动二周目动机。
- **发行平台与定价**：Steam / itch.io 是独立 VN 的主要发行渠道；PC 端日系 VN 有成熟付费意愿（10-30 美元区间），但需通过内容分级标注（全年龄 / 18+ 内容与平台政策的合规处理）；手机端则通常采用免费 + 章节解锁或订阅制。

## 经典参考作品

- **命运石之门（Steins;Gate）**：科幻叙事与时间线分支结构的典范，"真结局须先触发多条坏结局"的机制设计使玩家通关史本身成为叙事体验的一部分；文本张力与世界观构建业界顶级。
- **Doki Doki Literature Club（DDLC）**：以元叙事（meta-narrative）打破类型期待，利用 VN 媒介本身的存档、文件系统作为叙事装置；证明低成本（免费发行）加高概念创意可在全球市场制造病毒传播效果，是独立 VN 的重要参照。
- **428 ~封锁的涩谷~**：多主角平行叙事 + 实拍画面的实验性 VN，各主角时间线互相影响（一条线的选择解锁另一条线的通路），叙事结构设计在品类中具有独创性。
- **底特律：变人（Detroit: Become Human）**：互动叙事游戏（西方 VN 化）对分支可视化（章节结果图）的最佳实现，场景级选择与后续叙事连锁反应设计清晰；是向非 VN 玩家推介"互动叙事"设计理念的最佳案例。
- **心跳回忆（Tokimeki Memorial）**：恋爱模拟 / 育成型 VN 的奠基作，好感度多维参数（运动/智力/外貌等）与校园日历系统成为后续恋爱游戏的设计原型，定义了"日程管理 + 好感度养成"子类型。
- **弹丸论破（Danganronpa）**：侦探推理 + VN 叙事 + 小型游戏（班级审判）的混合品类，用机制化的审判段打破纯文字的被动阅读，使核心推理参与感大幅增强；是叙事 VN 与机制融合设计的重要参照。

## 常见坑

- **分支结构过于复杂（网状爆炸）**：试图在所有节点做出"完全有意义的分支"会导致内容量指数级膨胀，大量分支内容无法被玩家发现；优先采用主线单轨 + 角色线分支的树形结构控制开发成本。
- **选择缺乏真实意义**：如果大多数选择实际上导向相同的后续内容（仅对话略有差异），玩家会快速意识到"选什么都一样"，能动感与沉浸感双双崩溃；每个有意义的分支节点应确保至少有一条显著不同的叙事走向。
- **文本质量参差不齐**：VN 以文本为核心，文字节奏、角色声音一致性、情感弧度的控制是首要质量门槛；技术实现简单但写作质量难以速成，过长的无聊段落（padding）或角色语气前后矛盾是最常见的质量杀手。
- **演出与文本情感脱节**：立绘差分不够（一张表情应对所有情绪）、BGM 切换不当（关键悲剧场景播放轻快音乐）、配音情感与文本语气不符——这些失误会直接破坏沉浸感，而立绘差分规划不足是独立 VN 最高频的问题。
- **忽视 UI/文本可读性**：文字排版、字体选择、行距、文本框透明度、语速控制（auto 模式速度）是容易被低估的体验细节；不舒适的阅读体验会加速疲劳，在文本量大的作品中尤为致命。
- **多结局动机不足**：若二周目仅有少量差异文本而无 CG、配乐或关键剧情转折作为奖励，玩家缺乏动力完成全收集；真结局的解锁条件应向玩家明确提示（或通过画面暗示），而非依赖攻略外挂。

## 单人/小团队可行性

**极高，是独立开发最友好的品类之一，也是 solo 创作者的经典入门路径。** 核心优势在于技术复杂度低（Ren'Py、Tyrano Builder、Unity 等引擎均提供成熟 VN 框架，主体代码工作量以周计）、无联机需求、无实时物理与判定设计，产能瓶颈几乎完全集中在**写作（文本量）+ 美术（立绘/CG/背景）**两项可分阶段外包或自学的创作技能上。Doki Doki Literature Club 由单人（Dan Salvato）制作并免费发布后获得全球关注，是 solo VN 最著名的成功案例。务实策略：① 用 Ren'Py（Python 脚本，免费，Steam 直接构建支持）快速搭建原型，将时间集中在内容而非引擎开发上；② 用 AI 绘画辅助生成背景（写实风格）或立绘草案，降低美术门槛；③ 优先选择角色数量少（3-5 人）、结局数量精（3-5 个）的精品短篇而非多线大作，精准控制首作体量；④ 无配音 / 关键场景配音的折中方案可将声优成本控制在可接受范围；⑤ 平台选择 Steam（付费）+ itch.io（免费试玩版）的双轨发行策略可最大化曝光与商业回收。
