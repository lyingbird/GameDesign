# 核心循环：核心动词、微/中/宏循环、正反馈链

## 核心概念

核心循环是"玩家**反复**在做的那件事"。一个游戏的留存与乐趣，本质由其循环质量决定。结构分三层尺度：

**核心动词表**：先列出玩家反复执行的 4~7 个动词（每个是一个可操作的行为）。例：选择 / 派遣 / 收取 / 修复 / 研究 / 配置 / 突破。动词必须是玩家**主动做**的事，不是系统替他做的事。

**微循环（micro，秒~分钟级）**：单次上线就能完整跑一遍、立刻拿到反馈的最小回路。
> 选择任务 → 派遣 → 获得产出 → 立刻点亮一个小节点
- 要求：**快速给反馈**，避免玩家上线只能看到遥远目标。
- 配**验收指标**：首次完成核心行为 ≤5 分钟、看到第一次变化 ≤10 分钟等。

**中循环（meso，小时~天级）**：支撑"阶段目标"的回路，玩家围绕一个馆区/关卡/解锁做规划。
> 修复馆区 → 开放新技能 → 产出门槛资源 → 解锁质变
- 配阶段目标验收指标（第一个核心解锁 2~4 小时、第二阶段 1~2 天…）。

**宏循环（macro，周~月级）**：长期留存核心。每次完成 = 一次**系统质变**，让玩家重新评估已有系统、重组构筑。
> 获得核心解锁 → 改写全局规则 → 重组构筑 → 进入更高阶内容 → 回到主循环起点
- 配长线指标（首版体验时长 4~6 周、后期突破靠构筑优化而非纯等待）。

**正反馈链（positive feedback chain）**：把三层循环串成一句**闭合**的因果链，且**末端回到起点并放大**。
> 知识 → 馆区 → 禁书 → 构筑 → 更高阶知识
逐条展开为 6~8 步的产出→消耗→解锁→反哺链路。关键：**链路必须闭合**（终点反哺起点效率），否则不是循环而是单向流程。

## 在问答中如何用（core_loop 节点）

进入 core_loop（在 genre_scope 重度门禁之后），harness 用本卡驱动：

1. **先抽核心动词**。提问"玩家在这个游戏里反复做的几件事是什么？"基于已确认的品类/系统给推荐动词表（4~7 个），option_id:0 让玩家补充。校验：动词是主动行为、彼此不重复。
2. **自下而上建三层循环**。
   - 微循环：问"一次上线 1~10 分钟，玩家走完哪个最小回路、能看到什么变化？"——必须能在分钟级给反馈。
   - 中循环：问"几小时到几天里，玩家围绕什么目标规划？"——对齐一个阶段解锁。
   - 宏循环：问"周到月尺度，什么让玩家愿意长期回来？"——必须对应一次**系统质变**，而非更高倍率。
3. **每层配验收指标表**（时间锚点 → 目标），作为后续模拟与体验校验的标尺。
4. **生成正反馈链句 + 6~8 步展开**作为检查点核心。让玩家确认"这条链闭合吗、终点是否反哺起点"。
5. **一致性校验**：循环里出现的资源/系统必须在 systems_resources 已定义；宏循环的"质变"应呼应 design_pillars 的差异化支柱。

收敛判据：核心动词表 + 微/中/宏三层（各带验收指标）+ 一条**闭合**正反馈链 → 出检查点。

## 反模式/坑

- **只有一层循环**：只描述了"打怪→升级→打更强的怪"，没区分微/中/宏 → 短期有反馈但长期空洞，或长期有目标但上线无即时反馈。三层都要。
- **循环不闭合（单向流程）**：写成"做A→做B→做C"的线性任务链，末端不回到起点 → 不是循环，留存差。正反馈链终点必须反哺起点效率。
- **宏循环只是"更高倍率"**：长期目标只是数字变大，没有规则质变 → 玩家审美疲劳。宏循环每圈应带一次系统级质变（新规则/新维度）。
- **微循环反馈太慢**：上线后要等很久才看到变化 → 流失。微循环必须分钟级出反馈。
- **动词是被动的**：把"等待""挂机"当核心动词 → 玩家没有能动性。挂机品类的核心动词应是"配置/派遣/规划"，等待只是结算方式。
- **循环与系统/资源脱节**：循环里的名词在 systems_resources 里找不到对应 → 后续无法落地。循环必须用已定义的系统和资源表达。
