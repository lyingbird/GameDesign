# 品类定位：一句话定位、竞品对标、差异化锚点、Scope 体量

## 核心概念

genre_scope 节点回答"**像谁、做多大**"，并且是**重度阶段门禁**（此节点末尾检查点标题"⭐ 确认后进入重度阶段"，前 4 节点轻量澄清，确认后才进入系统/数值/装箱等高成本生成）。四部分：

**一句话定位（positioning statement）**：把"差异化 + 主对标 + 题材"压成一句。
> 一款以禁书规则改写为核心差异化的魔法图书馆挂机 RPG，结合 Melvor Idle 式长线成长与轻经营式馆区修复。
句式 = `一款以【差异化锚点】为核心的【题材】【品类】，结合【主对标】式【X】与【副元素】`。

**竞品对标（competitor benchmark）**：选 1 个**主对标** + 1~2 个**气质参考**。每个写清：
- 主对标（学结构）：明确"**重点学习什么**"（多技能成长、长线目标、装备收集、离线收益、阶段解锁…）+ 明确"**不追什么**"（不追内容规模完全对标）。
- 气质参考（学调性）：学题材氛围/包装感，但点明"不做它的哪部分"（不做高频议价、不做永久损失压力）。

**差异化锚点（differentiation anchor）**：项目区别于所有竞品的**那一个**核心机制，且用"传统是X，我们改成Y"对比说清。实测："传统挂机解锁=更高倍率/等级/资源；本项目核心禁书必须**改变系统运转方式**"，并给 6 个"原本…变成…"的具体例子。差异化锚点应与 design_pillars 第一支柱一致。

**Scope 体量（S/M/L sizing）**：用一句话定体量 + 核心系统数 + 开发周期 + 风险灯号。示例表述：
> 中等偏小体量，可商业化首发，约 5~7 个核心系统，9~15 个月开发周期。
- 列出**已确认的核心系统清单**（通常 4~7 个）。
- **资源风险灯号**：🟢可控 / 🟡可控但需严控 scope / 🔴高风险。并点明主要风险来源（成熟实践表明：主要风险通常不是玩法原型，而是内容量/数值平衡/系统协同/UI 维护膨胀）。

Scope 粗分（供推荐）：
- **S（小）**：1~3 核心系统，3~6 月，单人~小团队，单一循环打磨。
- **M（中）**：4~7 核心系统，9~18 月，小团队，多系统协同（实测项目属此档偏小）。
- **L（大）**：8+ 核心系统，18+ 月，需团队，内容/运营驱动。

## 在问答中如何用（genre_scope 节点）

genre_scope 节点为 question → checkpoint（重度门禁）。harness 用本卡：

1. **定主对标**。基于已确认品类，问"最像哪款已上市游戏？"给推荐（带理由：结构成熟、可借鉴、玩家好理解），option_id:0 自定义。**主对标只选一个**（多了无法对齐结构）。
2. **拆"学什么/不学什么"**。对主对标追问"重点学它的哪几点、不追它的哪部分"——这是控 scope 的关键（学结构不学规模）。再补 1~2 个气质参考。
3. **逼出差异化锚点**。问"那这游戏凭什么和主对标不一样？"要求用"传统是X→我们改成Y"表达，并给 3~6 个具体例子。校验：锚点 = design_pillars 第一支柱。
4. **定 Scope + 风险灯号**。问"首版做多大？核心系统几个？大概多长开发周期？"给 S/M/L 推荐（结合团队规模/单人约束），列核心系统清单，点风险灯号 + 主要风险来源。
5. **生成定位卡（一句话定位 + 竞品 + 锚点 + Scope）作为重度门禁检查点**，标题带"⭐ 确认后进入重度阶段"。

收敛判据：一句话定位 + 主对标(学/不学) + 差异化锚点(对比式) + Scope(体量/系统数/周期/灯号) → 出门禁检查点。

## 反模式/坑

- **多个主对标**："像A又像B又像C" → 无法对齐任何结构，玩家也抓不住定位。主对标只选一个，其余降为气质参考。
- **对标=照抄**：把主对标当抄袭目标，连内容规模一起对标 → scope 爆炸（见 references-benchmarking）。对标是"标尺"，学结构不学规模。
- **差异化是形容词**："更好玩""更有深度" → 不是锚点。锚点必须是一个可指认的机制差异，且能用"传统X→我们Y"说清。
- **没有 Won't 对标**：只说学竞品什么，不说不追什么 → scope 失控。每个对标都要带"不追/不做"。
- **Scope 拍脑袋无灯号**：不给风险等级和风险来源 → 后续重度阶段无成本意识。必给灯号 + 主要风险来源（通常是内容量/平衡/UI，而非原型）。
- **定位与幻想/支柱不一致**：差异化锚点和 design_pillars 第一支柱不是同一件事 → 项目精神分裂。两者必须对齐。
