# 数值骨架：公式方向、Tier 体系、成长曲线、经济模型

## 核心概念

数值骨架**不是填满数值表**，而是定下**公式方向**与**参数区间**，让数值有结构、可模拟、可调。它是把前面（系统/资源/循环）的定性结论翻译成可平衡的定量框架。标准产出结构：核心公式方向 → 各类公式 → 参数区间 → Tier 体系 → 基准表 → 成长曲线 → 经济模型 → 风险点。

### 1. 核心公式方向（最先定）
一句话定下整体数值结构。推荐采用 **"分层乘法 + 边际衰减"**：
> 不同系统（馆区/技能/装备/规则）处在**不同乘区**，保证每个系统都有存在感；**同类加成做递减**，避免长期叠乘爆炸。

常见可选方向（harness 给推荐 + 理由）：
- **分层乘法 + 边际衰减**（推荐，多系统并存、易控爆炸）：`产出 = 基础 × A倍率 × B倍率 × … × 修正`。
- 纯加法（简单但后期乏力）；纯指数（爽但极易爆炸）；分段函数（控制力强但难调）。

### 2. 各类公式（给出口径，不堆数）
- **核心产出公式**（乘区相乘）：
  ```text
  产出 = 基础产出 × 系统A倍率 × 系统B倍率 × 系统C倍率 × 规则倍率 × 修正系数
  ```
- **边际衰减（同类加成）**——叠乘爆炸的解药：
  ```text
  有效加成 = 原始加成 / (1 + 原始加成 × 衰减系数)   # 衰减系数 0.35~0.60
  ```
- **时长/速度公式**（同样用边际衰减），并设**下限**防瞬间完成：
  ```text
  实际时长 = 基础时长 / (1 + 速度有效加成)
  实际时长 ≥ 基础时长 × 20%
  ```
- **离线/被动收益公式**（挂机品类必给，防穿透）：
  ```text
  有效离线时长 = min(实际离线, 离线上限)
  完成次数   = floor((已有进度 + 有效离线 × 离线效率) / 实际时长)
  离线收益   = 完成次数 × 单次收益 × 规则修正
  # 溢出处理：超上限默认不结算；特定规则可低比例(如10%)转化为软回收资源
  ```

### 3. 参数区间（给区间而非定值）
每个乘区给一个**首版骨架区间**，例：馆区 1.00~3.00 / 技能 1.00~2.50 / 装备 1.00~2.20 / 规则单本 1.10~1.80 / 离线修正 0.60~1.00 / 同类衰减 0.35~0.60。配一个**算例**把数代进去算出最终产出（例：100×1.4×1.571×1.25×1.2×0.75≈247），让区间可感知、可校验。

### 4. Tier 体系
把内容切成 3 层（早/中/后期），每层给：倍率区间、基础时长、产出倍率（相对 Tier1，如 3~8×、8~25×）、门槛资源产出、目标节奏（分钟→小时→天→周）。

### 5. 基准表
每 Tier 给一张**任务/节点样例表**：任务名 | 时长 | 各资源产出 | 概率 | 用途。这是把公式落到具体内容的"标尺"（每 Tier 建议 5 行样例，数值跨度随 Tier 放大 ~10×/层）。再给**成本基准表**（如节点成本 50~1000 / 1500~25000 / 30000~500000）。

### 6. 成长曲线
一句话定形状。推荐 **"前快中稳后软墙"**：前期快速展开多次反馈；中期目标转小时~天级、开始取舍；后期**软墙**（靠构筑优化突破，不硬卡死、不靠纯等待）。

### 7. 经济模型
一句话总括源汇基调，例如 **"主资源宽产出 + 阶段性硬消耗 + 软回收"**。并点名**最高优先级风险**（通常为"叠乘爆炸 + 离线收益穿透"）+ 待模拟验证清单。

## 在问答中如何用（numeric_skeleton 节点）

该节点为**自动 checkpoint（可超时）**——通常不向用户多问，而是 harness 依据 designContext（已确认的系统/资源/循环）**直接生成**这套骨架，必要时只在"核心公式方向/成长曲线形状"上给 1~2 个带推荐的确认问题。

1. **方向先行**：先生成"核心公式方向"和"成长曲线形状"两句话，给推荐（分层乘法+边际衰减 / 前快中稳后软墙）+ 理由（控爆炸、可平衡、适合单人调参）。
2. **逐公式产出**：把核心产出、时长、（若是挂机/被动品类）离线收益三类公式写成 code block，**每条公式都要带边际衰减或上限**，否则后期必爆。
3. **给区间不给定值**：所有乘区给区间 + 一个算例；区间宽度要让"早期到后期"有 ~数十倍总成长但单步可控。
4. **Tier × 基准表**：3 层 Tier，每层一张任务样例表 + 成本基准表，数值跨 Tier 放大 ~5~10×。
5. **收尾经济模型 + 风险清单**：用一句话经济模型 + 点名最高优先级风险 + 列"待模拟验证项"（衰减是否够、离线上限是否合理、规则倍率边界、是否跳过节奏、是否单路线垄断），直接喂给后续 simulate_verify 节点。

收敛判据：核心公式方向 + ≥3 类带衰减/上限的公式 + 参数区间&算例 + 3 层 Tier + 基准表 + 成长曲线 + 经济模型 + 风险清单 → 出 checkpoint。

## 反模式/坑

- **纯加法/纯指数无衰减**：加法后期乏力，指数必爆炸。多系统并存时用"分层乘法 + 同类边际衰减"。
- **不设乘区，所有加成同池叠加**：失去"每个系统都有存在感"，且无法定位爆炸来源。按系统分乘区。
- **速度/时长没有下限**：速度堆叠 → 任务瞬间完成 → 经济穿底。必须设 `实际时长 ≥ 基础时长 × 20%` 之类下限。
- **离线收益线性无上限**：玩家放置越久越暴富，且鼓励"挂机不上线"。必给离线上限 + 离线效率<100% + 溢出处理。
- **只给定值不给区间/算例**：无法平衡、无法模拟、无法交给 simulate_verify。永远给区间 + 一个代入算例。
- **Tier 跨度过大或过小**：每层产出建议 ~5~10× 放大；过大则中期断层，过小则后期无新鲜感。
- **不点风险**：不交出"待模拟验证清单"，下游节点无从验证。务必显式列出叠乘爆炸、被动穿透、单路线垄断等高危项。
