# 参考作品与对标：把参考游戏当"设计标尺"，不是抄袭对象

## 核心概念

参考游戏的正确用法是当**设计标尺（design ruler）**：用一款玩家和团队都熟悉的成熟游戏，作为"结构/节奏/数值/体量"的参照系，从而（a）快速对齐设计语言，（b）精确表达差异——"我们和它一样的是X，不一样的是Y"。错误用法是当**抄袭蓝图**：连内容规模、系统数量一起照搬，导致 scope 爆炸或失去灵魂。

**两类参考，分清用途**：
- **结构标尺（主对标，1 个）**：学它的**循环结构 / 成长节奏 / 系统骨架 / 数值量级**。明确"学这几点"。例：Melvor Idle → 多技能成长、长线挂机目标、离线收益、阶段解锁。
- **气质参考（1~2 个）**：学它的**题材氛围 / 包装感 / 情绪基调**，不碰它的机制深度。例：Cultist Simulator → 危险知识、神秘学氛围；但不做它的高压惩罚和叙事卡牌。

**标尺的三个具体作用**：
1. **校准量级**：用对标的数值/内容量级当锚（"它有约 N 个技能，我们首版做 N/3"），避免凭空定数。
2. **表达差异**：差异化锚点必须相对参考来定义——"传统挂机（如它）解锁=更高倍率；我们改成规则改写"。没有参考，差异说不清。
3. **控制 scope**：每个参考都要配一句"**不追什么**"，把"学结构"和"抄规模"切开。

**"学什么/不学什么"是核心动作**：每个参考都要拆成两栏——
- 学：可借鉴的结构/节奏/数值（降低设计与沟通成本）。
- 不学/不追：明确放弃的部分（防 scope 膨胀、防丢差异化）。

## 在问答中如何用（creative_intake + genre_scope 节点）

**在 creative_intake**（此节点会依次问 品类→题材→核心想法→**参考作品**）：
- 引导玩家说出 1~3 个"你心里像谁"的参考，作为后续节点的上下文锚。
- 此时只**收集**参考 + 玩家说的"像在哪"，不急于定主/副，留给 genre_scope 收敛。
- 把参考作为**强约束注入** designContext（用户自定义的参考会让后续节点的推荐项、题材、核心机制全部据此收敛）。

**在 genre_scope**（定主对标/气质参考/差异化）：
1. **从收集到的参考里推一个主对标**，给理由（结构最接近、玩家最熟、可借鉴度最高），option_id:0 让玩家换。
2. **对主对标做"学/不学"两栏**：问"重点学它哪几点、坚决不追它哪部分"。这是把标尺和抄袭分开的关键提问。
3. **用参考表达差异化**：问"相对它，我们最不一样的一个机制是什么？"用"它是X→我们是Y"句式。
4. **用参考校准 Scope 量级**：问"它的体量多大？我们首版做它的几分之几？"得到带锚的体量判断。
5. 把气质参考也各配一句"学氛围、不做它的某机制"。

收敛判据：1 主对标(学/不学两栏) + 1~2 气质参考(学氛围/不做某项) + 相对参考定义的差异化锚点 + 相对参考校准的体量 → 喂给 genre-positioning 卡产出定位。

## 反模式/坑

- **参考当蓝图照抄**：连系统数、内容量一起对标 → scope 爆炸 / 没有差异化 → 沦为"换皮"。永远配"不追什么"。
- **参考太多无主次**：列 5+ 个参考且不分主/气质 → 无法对齐任何结构。主对标只 1 个。
- **只学不切**：说学某游戏但不说"不学它哪部分" → 不知不觉把对方的重型系统都搬过来。
- **没有参考就定差异化**：脱离参照系谈"我们很创新" → 差异说不清、玩家也理解不了。差异必须相对某个参考定义。
- **气质参考混进机制**：把气质参考的核心机制也学过来（如学了 Cultist Simulator 的永久损失压力）→ 违反 Won't-Do、撕裂体验。气质参考只学氛围。
- **量级不锚定**：不借参考校准就拍脑袋定"做 100 个技能" → 与团队产能脱节。用参考的量级 / N 来定首版体量。
