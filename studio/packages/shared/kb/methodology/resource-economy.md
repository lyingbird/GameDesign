# 资源经济：源汇关系与闭环验证

## 核心概念

游戏经济 = 一组**资源**，每种资源有若干**源（faucet/产出）**和**汇（drain/消耗）**，源汇之间通过玩法行为连成**闭环**。健康经济的判据不是"数值大小"，而是"**每种资源都既被产出、又被消耗，且消耗能回流提升后续产出效率**"。

**三资源分工模板**（以《典藏图书馆》为示例，是挂机/经营品类的强模板）：
- **主产出资源**（高频、宽产出）：提供即时反馈，玩家每次上线都能看到它增长并花掉。例：知识碎片。要求"产出相对宽、消耗频率高、保证短时上线能看到变化"。
- **门槛资源**（稀缺、阶段性、硬消耗）：控制阶段节奏的闸门。例：禁书钥印。要求"不能过宽否则节奏失控，不能过窄否则中期卡死，应作为阶段目标核心"。
- **软回收资源**（长期、可重复花费）：承接中后期持续消耗、构筑深化。例：灵墨。要求"略滞后于主产出、中后期形成持续消耗、防止系统无成本频繁洗换"。

**源汇关系（source/sink 表）**：每种资源都要列清——
- 源：哪些玩法行为产出它（任务/离线/节点/规则改写/被动）。
- 汇：哪些系统消耗它（升级/解锁/强化/重铸/突破）。
- 经济要求：产出宽窄、消耗频率、与其它资源的时序关系（谁滞后于谁）。

**资源闭环（核心句式）**：用一句"A产出→B消耗→解锁C→D消耗→反哺A效率"的链路表达整个经济。以《典藏图书馆》为例：
> 研读产出知识碎片 → 修复馆区 → 解锁钥印与技能 → 解读禁书改写规则 → 用灵墨强化技能与装备 → 提升更高阶研读效率

**分阶段节奏表**：每种资源在 Tier 1/2/3（早/中/后期）的产出与消耗定位用表格给出（宽松/稳定/高产出；稀少/有限/控制终局）。给出**单日产出/消耗参考区间**（示例：软回收资源 Tier1 日产 5~30、Tier2 80~500、Tier3 1000~8000）。

## 在问答中如何用（systems_resources 节点）

进入 systems_resources 后半段（系统列完、开始定资源流）时，harness 应用本卡驱动以下提问与产出：

1. **先定主资源数量与分工**。提问："这个游戏玩家主要在积累和消耗哪几种资源？"推荐用"主产出/门槛/软回收"三资源模板（给理由：主资源给反馈、门槛资源控节奏、软回收承接长线消耗，对单人/小团队最易平衡）。option_id:0 留给自定义资源结构。
2. **逐资源问源与汇**。对每种资源连续追问"它从哪来（源）/花到哪去（汇）"，并把答案落成 source/sink 列表。校验：**每种资源至少 1 源 + 1 汇**；只产不耗或只耗不产的资源必须改。
3. **让玩家确认闭环句**。生成那条"A→B→C→反哺A"的链路句作为检查点预览核心，问"这个闭环成立吗/哪一环断了"。
4. **生成分阶段节奏表 + 日产消参考区间**作为检查点产出（覆盖早中后三期的表格密度）。
5. **跑闭环验证清单**（见下）当作收敛判据，逐条过；任何一条不成立就回到对应维度再问一轮。

实测闭环验证清单（直接作为本节点的"产出 schema 自检项"）：
1. 主资源足以推动早期第一个消耗（前期不卡）。
2. 每个解锁必须开放**新资源入口**，而不是只给倍率。
3. 门槛资源必须成为中期目标。
4. 关键解锁后必须**改变玩家配置策略**（否则只是数值膨胀）。
5. 软回收资源必须有长期消耗点。
6. 强化/装备类消耗必须**回流到核心产出效率**。
7. 离线/被动收益**不能绕过门槛资源节奏**。
8. 配置/专长必须影响行为选择。
9. 可叠加属性必须有上限（防失控）。
10. 任何风险/副作用不能造成**永久损失**。

收敛判据：三资源分工 + 每资源源汇齐全 + 一条成立的闭环句 + 分阶段节奏表 → 出检查点。

## 反模式/坑

- **单资源经济**：只有一种"金币"包打天下，没有门槛资源 → 没有节奏闸门，玩家要么卡死要么暴富。至少分出"高频反馈资源"和"阶段门槛资源"。
- **产出无消耗（资源溢出）**：某资源越攒越多没处花 → 玩家失去目标感。每种资源必须有持续的、随阶段升级的汇。
- **消耗不回流**：花掉资源只换来一次性数值，不提升后续产出效率 → 正反馈断裂，长线动力消失。消耗必须接回"提升产出效率"。
- **只给倍率不给入口**：解锁内容只是 +X%，不开放新玩法/新资源源 → 玩家感知不到质变（见 design-pillars 的"禁书改写规则"反例）。
- **离线/被动穿透节奏**：被动产出绕过门槛资源，让玩家跳过设计好的阶段 → 经济崩坏。被动收益要受门槛资源约束（钥印仍需主动行为）。
- **节奏区间拍脑袋**：不给单日产出/消耗参考区间，后续 numeric_skeleton 无法落数。本节点要交出**带区间的节奏表**，给数值节点当锚。
- **资源种类过多**：5+ 种主资源 → 玩家算不过来、平衡爆炸。MVP 控制在 3 种核心资源（可加 1~2 种线索/进度类辅助资源）。
