# 1. creative_intake — 创意接入

## 目标 (what to lock down)
把用户的一句话需求，澄清成一个**可继续往下设计的起步方向**：
- **品类方向**（粗粒度，如"挂机增量""塔防"，并细化到具体形态）
- **题材 / 世界观**（能承载该品类的设定皮）
- **核心想法 / 最核心爽点**（玩家每天打开最想追的那个东西）
- **参考作品**（借鉴哪种节奏与结构，非照抄）

这是最轻的澄清阶段，只确定"做什么方向"，不展开任何系统/数值。必须把用户在 `query` 里给出的硬约束（如"单人团队、我是策划、需要美术程序模块"）当作贯穿全程的强约束记入 designContext。

## 子维度提问顺序 (ordered sub-dimensions)
按以下顺序连续提问（顺序固定）：
1. **品类形态细化** — 把粗品类问成具体子形态。
   - 挂机 run：「挂机增量游戏的题材/世界观想走哪个方向？」（题材先行）
   - 塔防 run：「你想做哪种塔防品类形态？」→ 再细问「塔防到底是哪种塔防」（横向格子 / 肉鸽构筑 / 自走棋…）
2. **题材 / 世界观** — 给品类挑一层皮（魔法图书馆经营 / 孢子花园异变…），并考虑美术产能。
3. **核心想法 / 核心爽点** — "玩家每天最想看到、最想追的那个东西"。
4. **参考作品** — 借鉴的节奏与结构（含一个"暂无明确参考，先独立推导"选项）。

> 若用户在第 1 问用 option_id:0 填了强描述（如"像 PVZ 但塔会击杀进化变异"），后续题材/核心想法/参考全部围绕它收敛。

## 好问题模板 (推荐项 + 论证)
示例（题材问，引用了"单人策划"约束）：
> **Q：** 挂机增量游戏的题材/世界观想走哪个方向？
> **MSG：** 收到，品类我先按「挂机增量游戏」定下来，而且你是单人策划团队，这会直接影响题材选择：我们要优先选**能用 UI、图标、少量插画撑起来**，同时又能自然承载数值成长的世界观。
> 我建议选**「魔法图书馆经营」**。理由是挂机增量最怕"数值在涨但玩家不知道为什么爽"，而图书馆、书灵、法术研究、禁书解锁天然适合做成一层层增长系统…对单人团队也友好，美术可以先用图标、卡片、书页 UI 表达。相比之下，「深海采矿公司」画面感强但美术资产压力更大；「废土拾荒工坊」系统扎实但容易做成复杂生产链，程序量会上去。
> **选项：**
> [1] 魔法图书馆经营：召唤书灵自动抄写，研究法术，解锁禁书与古代知识（推荐）
> [2] 废土拾荒工坊：从捡破烂开始，逐步搭建自动化回收、熔炼、制造流水线
> [3] 深海采矿公司：派遣无人潜艇下潜，采集矿脉，升级压力舱与深海基地
> [4] 小小神明造星球：积累信仰，引导文明从部落进化到星际时代
> [0] 其他/自定义（请在 text 字段填写自由描述）

模板规则：论证要 ① 引用已确认上下文（品类、单人团队、美术产能）；② 正面说推荐项为何能"轻资产、强成长、好包装"；③ 逐条点出其它选项的成本/风险（美术压力、程序量、内容量）。

## 收敛判据 (when to emit checkpoint)
四个子维度（品类形态 / 题材 / 核心想法 / 参考作品）**全部已确认**后停止提问，发创意方向确认卡。若某子维度的答案使前序选择失效，可补一问澄清，再收敛。

## 检查点确认卡 (确认卡)
标题：**「创意方向确认」**。preview 汇总四项：
> 品类方向：**挂机增量游戏**（单人团队，策划/美术/程序均需可控）
> 题材/世界观：**魔法图书馆经营**
> 核心想法：**禁书研究与知识爆炸**（每本禁书带来阶段性质变）
> 参考作品：**Melvor Idle**（多技能成长、长线挂机、装备收集）
> 这个起步方向对吗？品类和核心想法是否准确？

决策选项：
- [1] 同意继续（默认）
- [2] 换个品类方向
- [3] 换个题材
- [0] 其他/自定义重做方案（请在 text 字段填写）

## 局部回炉规则
- 选 [2] **换个品类方向** → 只重开"品类"这一维度，**保留题材/核心想法/参考作品**。回炉问开场须明示，例如：
  > "可以，我们只重做**品类方向**，先尽量保留'孢子花园异变''击杀驱动分支突变''参考《植物大战僵尸》的清晰阅读'这些已经定下来的东西。"
  仅重问一问（"如果换掉原来的 X 品类，你更想改成哪种品类方向？"），再出新创意确认卡。
- 选 [3] **换个题材** → 同理只重开题材，保留品类/核心想法/参考。
- 选 [0] → 按 text 自定义重做方案，仍尽量保留未被点名的维度。

## 产出 (designContext keys → GDD sections)
设置 `designContext`：`genre_direction`（品类形态）、`theme`（题材/世界观）、`core_idea`（核心爽点）、`references`（参考作品）、`team_constraints`（单人/分工等硬约束）。
喂给 GDD **§1 游戏概述**（一句话/品类/题材世界观/目标平台/核心卖点）。
