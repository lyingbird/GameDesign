# 2. core_fantasy — 核心幻想

## 目标 (what to lock down)
锁定"玩家为什么愿意每天回来"，三件事：
- **核心幻想 / 玩家扮演的角色**（玩家在游戏里"是谁"、追求什么样的体验感，一句话）
- **目标核心玩家**（这游戏优先服务哪类玩家 → 决定深度方向：轻松收菜 / 深度规划 / 收集养成）
- **差异化锚点**（玩家为什么不玩别的同类，而玩你的——产品钩子）

承接 creative_intake 的题材+核心想法，把"做什么"升级成"给谁带来什么独特体验"。仍是轻量澄清。

## 子维度提问顺序 (ordered sub-dimensions)
固定三问：
1. **玩家扮演什么角色 / 核心幻想**（"玩家在这个游戏里到底是谁"）。
2. **目标玩家是谁**（应优先服务哪类核心玩家）。
3. **差异化锚点**（相比同类，最核心的差异是什么）。

## 好问题模板 (推荐项 + 论证)
示例（差异化问，引用了已定的核心想法 + 目标玩家）：
> **Q：** 这款游戏和其他挂机 RPG 相比，最核心的差异化是什么？
> **MSG：** …现在进入最后一个维度：差异化。也就是玩家为什么不继续玩别的挂机 RPG，而要玩你的《典藏图书馆》。
> 我建议选**「禁书改写规则：每本禁书都不是普通加成，而是改变图书馆运转方式」**。这个方向最能把你已经定下的"禁书研究与知识爆炸"变成真正的产品钩子。挂机增量最怕只有产量翻倍、效率提升，玩家很快麻木；但如果禁书会让"抄写产物反过来影响研究""某种资源变成另一种资源的燃料"，玩家每解锁一本都感觉打开了一条新规则。相比之下，「多技能学院式成长」会更像 Melvor Idle 换皮；「书灵队伍养成」美术和内容量压力更大；「低文本神秘叙事」气质好但单独撑不起长线挂机循环。
> **选项：**
> [1] 禁书改写规则：每本禁书都不是普通加成，而是改变图书馆运转方式（推荐）
> [2] 多技能魔法学院式成长：抄写、装订、炼墨、占星、召灵、封印等技能互相联动
> [3] 书灵队伍养成：不同书灵负责抄写、研究、守卫、探索，形成挂机编队策略
> [4] 低文本神秘叙事：通过书页碎片、禁忌注释拼出古代知识真相
> [0] 其他/自定义（请在 text 字段填写自由描述）

模板规则：目标玩家问的论证要引用**已选参考作品**（如"你已明确参考 Melvor Idle，它的核心用户是喜欢多技能并行、装备收集、阶段目标的玩家"）；差异化问的论证要紧扣**核心想法**并解释它如何成为长期钩子。

## 收敛判据 (when to emit checkpoint)
核心幻想 / 目标玩家 / 差异化锚点三项都确认后，发核心幻想确认卡。

## 检查点确认卡 (确认卡)
标题：**「核心幻想确认」**。preview 汇总三项：
> 核心幻想：玩家扮演一名**典藏图书馆**，在尘封魔法图书馆中驯服危险知识，逐步引发知识爆炸。
> 目标玩家：**喜欢长线规划的挂机 RPG 玩家**（享受多技能成长、装备收集、阶段目标、离线收益优化）。
> 差异化锚点：**禁书改写规则**——每本禁书都改变图书馆运转方式，让每次解锁都感到系统质变。

决策选项（注意：本节点只有 2 个决策项 + 自定义，因为三维度高度耦合，回炉作为整体重做）：
- [1] 同意继续（默认）
- [2] 换一个核心体验方向
- [0] 其他/自定义重做方案（请在 text 字段填写）

## 局部回炉规则
- 选 [2] **换一个核心体验方向** → 重开核心幻想这一维度（幻想/目标玩家/差异化作为一组重谈），但**保留 creative_intake 已确认的品类/题材/核心想法/参考作品**。回炉开场须说明"我们重新定核心体验，前面的品类与题材保持不变"。
- 选 [0] → 按 text 自定义重做，保留 P0 已确认内容。
