# 4. genre_scope — 品类定位

## 目标 (what to lock down)
把方向坐标钉死——"像谁、学什么、不学什么、做多大、靠什么被记住"：
- **品类组合**（主品类 + 副品类，如"挂机 RPG + 轻经营"）
- **竞品对标**（主对标 + 气质参考，明确"学其骨架、不追其内容"）
- **项目 Scope / 体量**（带颜色灯号的体量档位 + 核心系统数 + 工期）
- **差异化锚点**（在竞品矩阵里靠哪一句被记住）

**这是最后一个轻量澄清节点**：它的确认卡是刻意的成本闸门，确认后进入重度生成。

## 子维度提问顺序 (ordered sub-dimensions)
固定四问：
1. **品类组合**（主+副品类怎么组合）。
2. **竞品对标**（对标哪组——主对标学骨架，旁参作品借气质/包装）。
3. **项目 Scope / 体量**（🟢小 / 🟡中偏小 / 🟡中 / 🔴大，各带系统数与工期）。
4. **差异化锚点**（在竞品里靠什么被记住，通常呼应最高支柱）。

## 好问题模板 (推荐项 + 论证)
示例（Scope，引用了单人团队 + 已定品类组合）：
> **Q：** 项目范围定多大？
> **MSG：** 竞品坐标定了，现在评估项目体量。这一步要诚实：**挂机 RPG 的风险不在单个系统难，而在内容量和数值维护会持续膨胀**。
> 我建议选**「🟡中等偏小体量」**。你需要保住 Melvor Idle 式的多技能、装备、离线成长，又要做"禁书改写规则"和轻经营包装，太小会撑不起核心幻想；但你是单人团队，不能追 RuneScape 式海量内容。「🟢小体量」适合验证版但难形成长线留存；「🔴大体量」意味着内容生产、平衡测试、存档兼容和 UI 维护都会爆炸，除非有稳定多人团队。
> **选项：**
> [1] 🟡中等偏小体量：可商业化首发，约5~7个核心系统，9~15个月（推荐）
> [2] 🟢小体量：验证版，约3~4个核心系统，6~9个月
> [3] 🟡中等体量：完整长线挂机RPG，约8~10个核心系统，15~24个月
> [4] 🔴大体量：Melvor级内容追赶，10个以上核心系统，24个月以上
> [0] 其他/自定义（请在 text 字段填写自由描述）

模板规则：竞品问的论证须区分"主对标学什么、旁参借什么、各自不学什么"（如"学 Melvor 成长骨架，不追海量内容；借 Potionomics 经营包装，借 Cultist Simulator 危险知识氛围"）；Scope 论证须诚实点出最大风险（内容量/数值维护/UI 膨胀）并对齐单人团队约束。

## 收敛判据 (when to emit checkpoint)
品类组合 / 竞品对标 / Scope / 差异化锚点四项确认后，发**带成本闸门**的确认卡。确认卡 preview 还会给一个**资源风险灯号**（🟡可控但需严格控 Scope）。

## 检查点确认卡 (确认卡)
标题（特殊）：**「⭐ 方向可继续确认（确认后进入重度阶段）」**（成本闸门）。preview 汇总：
> 品类定位：**挂机 RPG + 轻经营**（主循环学 Melvor 长线挂机；轻经营承载图书馆/书灵/馆区/禁书）。
> 竞品对标：**Melvor Idle 主对标，Potionomics / Cultist Simulator 做气质参考**。
> Scope：**🟡中等偏小体量（约 5~7 核心系统，9~15 个月）**。
> 差异化锚点：**禁书改写挂机规则**。
> 资源风险灯号：**🟡可控但需严格控 Scope**（最大风险是内容量、数值平衡、协同与 UI 维护膨胀）。
> ⭐ 方向可继续确认：确认后进入主干施工阶段。

决策选项：
- [1] 同意继续（默认）
- [2] 品类定位有问题，重新讨论
- [3] Scope 太大，需要缩小
- [0] 其他/自定义重做方案（请在 text 字段填写）

## 局部回炉规则
- 选 [2] **品类定位有问题** → 只重开品类组合（必要时连带竞品对标），**保留 Scope 与差异化锚点之外的上游全部**；论证基于不变的支柱/幻想重提。
- 选 [3] **Scope 太大，需要缩小** → 只重开 Scope 这一维度，**保留品类组合/竞品/差异化锚点**，重问体量档位并强调"缩小"约束（如优先推 🟢/🟡 小档）。
- 选 [0] → 按 text 自定义。
> ⚠ 因为这是重度阶段闸门，回炉成本低于"确认后再发现错"，文案应鼓励用户在此把方向彻底敲定。

喂给 GDD **§4 品类定位与竞品**（定位/竞品对标/差异化锚点/Scope）。确认 = 进入 systems_resources 起的重度生成段。
