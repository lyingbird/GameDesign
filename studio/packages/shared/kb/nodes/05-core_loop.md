# 5. core_loop — 核心循环

## 目标 (what to lock down)
定义玩家"反复做什么"，并验证循环闭合：
- **核心动词**（玩家最频繁、最代表品类的动作组合，4 个动词串）
- **微循环（分钟级）**：打开游戏一次最小操作 → 立刻看到反馈
- **中循环（小时～天）**：几轮后形成的清晰阶段目标
- **宏循环（周～月）**：长期留存理由（每次大节点带来质变/新纪元）
- **闭合性**：奖励是否回流到下一轮行动（避免"做完不知道干嘛""大奖只是终点"）

这是重度阶段第一节点，仍是选择题问答，但答案直接决定后续系统与数值骨架。

## 子维度提问顺序 (ordered sub-dimensions)
固定五问：
1. **核心动词**（一组 4 动词的主循环，如"派遣研读→修复馆区→研究禁书→配置构筑"）。
2. **微循环（分钟级）**（最短反馈链）。
3. **中循环（小时～天）**（阶段目标链）。
4. **宏循环（周～月）**（长期质变链）。
5. **闭合性**（资源/奖励如何回流，给出一条闭环式资源链）。

每一层的论证都画出**正反馈链箭头**（A → B → C → 回到 A），并和上一层咬合。

## 好问题模板 (推荐项 + 论证)
示例（宏循环，引用差异化锚点 + 支柱）：
> **Q：** 宏循环选择
> **MSG：** 中循环已定，现在进入**宏循环（周～月）**：玩家长期留下来的理由，应该是"每本禁书都让图书馆进入一个新纪元"。
> 我建议选**「收容核心禁书→改写全局挂机规则→重组技能/装备构筑→解锁新馆层」**。这条宏循环最能放大项目差异化：禁书不是高级科技点，而是让玩家重新理解已有系统。正反馈链是：**修复馆区积累钥印 → 收容核心禁书 → 全局规则质变 → 旧技能旧装备出现新搭配 → 推进更深馆层 → 寻找下一本禁书**。如果选「持续扩建→提高总产能」长期稳定但容易变成普通经营放置；「赛季式重置」留存强却可能伤害长线挂机积累感；「收集全套装备→挑战终局首领」会把宏循环推向传统刷装 RPG，禁书系统质变被压扁。
> **选项：**
> [1] 收容核心禁书→改写全局挂机规则→重组技能/装备构筑→解锁新馆层（推荐）
> [2] 持续扩建馆区→提高总产能→开放更多建筑→形成大型自动化图书馆
> [3] 赛季式重置→保留禁书遗产→重新规划路线→冲击更高效率
> [4] 收集全套装备→挑战终局首领→进入下一难度→追求更稀有掉落
> [0] 其他/自定义（请在 text 字段填写自由描述）

模板规则：每层论证必须 ① 写出明确的正反馈链（带 → 箭头）；② 与上一层咬合（"承接微/中循环"）；③ 拒绝那些会把主题压扁成"普通刷怪/普通经营/纯数值"的选项，并点名它们违背了哪根支柱。

## 收敛判据 (when to emit checkpoint)
五个子维度（核心动词 + 微/中/宏循环 + 闭合性）全部确认后，发核心循环确认卡。

## 检查点确认卡 (确认卡)
标题：**「核心循环确认」**。preview 分层汇总：
> **核心动词**：派遣研读 → 修复馆区 → 研究禁书 → 配置构筑（核心身份=唤醒图书馆的馆长，非刷怪战士/纯店主）。
> **微循环（分钟级）**：选书架任务 → 派遣书灵研读 → 获得知识碎片/线索 → 立刻点亮一个小节点。
> **中循环（小时～天）**：修复馆区 → 开放新技能 → 产出禁书钥印 → 解读禁书改写规则。
> **宏循环（周～月）**：收容核心禁书 → 改写全局规则 → 重组构筑 → 解锁新馆层。
> **闭合性**：知识 → 馆区 → 禁书 → 构筑 → 更高阶知识。

决策选项：
- [1] 同意继续（默认）
- [2] 微循环不合理，重做
- [3] 宏循环缺失，补充
- [0] 其他/自定义重做方案（请在 text 字段填写）

## 局部回炉规则
- 选 [2] **微循环不合理** → 只重问微循环这一层，**保留核心动词/中循环/宏循环/闭合性**。
- 选 [3] **宏循环缺失** → 只重问/补宏循环这一层，保留其余层。
- 选 [0] → 按 text 自定义调整某一层。
回炉论证须显式说明"我们只重做 X 循环层，其它层保持不变"，并保证重做后整条闭合链仍咬合。
